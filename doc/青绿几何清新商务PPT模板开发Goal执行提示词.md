# 青绿几何·清新商务 PPT 模板 Goal 执行提示词

## 使用说明

本提示词已由用户明确启动，T1～T6 已完成，用户已明确回复“确认完成”，当前交付已闭合。实际进度和交付材料见 Goal 规划；后续续办时复用仍有效的实现与证据，不重新生成合格素材或重复开发。下方保留完整执行提示词供任务续办参考。

需要开始时，用户可以明确要求“按本文件执行”，或复制下方提示词发送。届时的实施范围包括 18 个版式、A1～A5 五张装饰、代码接入及必要验证；不包含 Git 交付和生产操作。

启动后 T1～T5 自动推进，执行者自行检查、记录结果、修复问题并继续。T6 自动检查通过并准备好交付材料后，必须等待用户明确确认，才能完成闭合和总 Goal；不增加其他逐页、逐图或逐任务审批。

- 任务与进度：[Goal 规划](青绿几何清新商务PPT模板开发Goal.md)
