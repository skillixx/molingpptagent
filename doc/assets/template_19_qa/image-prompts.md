# 水彩绿植轻商务模板图片生成记录

## 生成策略

- 工具：内置 ImageGen。
- 请求模型：GPT Image 2。
- 实际模型：工具未暴露。
- 参考用途：只参考《精品系列(21).pptx》的水彩植物语言、配色、边缘构图、留白和视觉重量。
- 禁止内容：文字、数字、Logo、水印、二维码、人物、产品界面和伪证据。
- 透明素材：要求真实 RGBA 和 Alpha，不接受棋盘格位图。

## 提示词摘要

| 素材 | 提示词重点 | 轮次 |
|---|---|---:|
| 封面背景 | 米白纸纹，右上和左下桉叶，中央偏左大留白 | 1 |
| 内容背景 | 近乎空白的暖白水彩纸纹，无明显植物主体 | 1 |
| 章节背景 | 下部浅弧桉叶，中心上部保持空白 | 1 |
| 结束背景 | 稀疏角部桉叶，与封面呼应但更安静 | 1 |
| 左下桉叶角景 | 透明背景，圆叶从左下向右上延伸 | 2 |
| 右上桉叶角景 | 使用已验证左下角景镜像形成稳定透明变体 | 1次确定性变体 |
| 横向桉叶 | 透明背景，浅弧横向枝条，不形成闭合花环 | 1 |
| 蕨叶侧景 | 透明背景，植物集中在右侧，左侧留文字区 | 1 |
| 叶片纹章 | 透明背景，松散圆环，中心大留白 | 2 |

## 失败记录

植物框连续3轮返回RGB棋盘格，没有真实Alpha。按单项最多3轮规则停止重试，并使用已验证透明的桉叶角景镜像为右上变体。原始失败文件只保留在本地QA目录，不进入生产模板。
