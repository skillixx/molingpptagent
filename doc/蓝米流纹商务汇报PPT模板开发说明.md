## 1. 模板定位和视觉边界

### 1.1 使用场景

模板服务于年中总结、年度总结、述职汇报、项目复盘、经营分析、项目规划和团队行动计划。

### 1.2 必须保持的视觉特征

- 深海蓝、灰蓝、浅青灰和象牙白形成低饱和配色。
- 流体矿物或大理石曲线作为背景和局部纹理。
- 普通内容页以白色为主，标题和重点信息使用深蓝。
- 封面和结束页使用同一流纹母题，形成首尾呼应。
- 章节页使用一块主要流纹切片、细框和连续留白。
- 内容页使用扁平、可编辑的文字和信息图结构。
- 流纹只承担背景和装饰角色，不能把业务文字烘焙进图片。

### 1.3 禁止的方向

- 霓虹科技蓝、玻璃拟态和密集仪表盘。
- 金色奢华石材、地产广告或珠宝风格。
- 水彩植物、厚重油彩、国潮水墨和星空科技。
- 把每个内容项都做成按钮、胶囊或重复卡片。
- 让高细节流纹覆盖普通正文区域。

本模板与现有 `template_20` 的油彩商务风格不同。不得复用 `template_20` 的素材、配色、构图碎片或命名。

## 2. 参考稿处理规则

参考 PPT 只用于提炼构图和页面关系。开发者按下表处理源内容：

| 源内容 | 处理方式 |
|---|---|
| 流体纹理图片 | 重新生成原创素材或使用授权明确的替代素材 |
| 示例风景照片 | 不进入模板资源，只提炼业务图片槽的构图 |
| 示例公司名、标题、正文 | 删除，换成中性可编辑示例 |
| 版权声明、下载提示和水印 | 删除 |
| MP3 音频 | 删除，不进入 JSON 或导出物 |
| 动画和页面切换 | V1 排除 |
| Century Gothic 等非项目字体 | 英文和数字使用 Arial，中文使用微软雅黑 |
| 图标、圆环、进度条、线条 | 使用项目支持的可编辑形状重建 |

源 PPTX 已能被项目的 `pptxtojson` 解析链路读出 25 页，但源文件缺少项目需要的页面类型和语义占位符。因此必须重建为 PPTist JSON，不能把源 PPTX 直接注册为生产模板。

| `template_21_asset_corner_flow_v1.png` | PNG RGBA，1200×900 | 850KB | 流纹只占一个角，中央至少 75% 透明 |

统一生成方向：深海蓝、灰蓝、浅青灰和象牙白的抽象流体矿物纹理，连续柔和曲线，商务质感，无文字、数字、Logo、水印、图标、人物、实物和界面。

素材规则：

- 背景使用 RGB JPEG，透明装饰使用 RGBA PNG。
- 每项素材使用独立提示词，不制作素材拼图再切割。
- 每项素材最多生成或重试 3 轮。
- 记录提示词、工具、实际模型、源输出、发布路径、尺寸、模式、体积和 SHA-256。
- 工具没有暴露实际模型名称时记录“工具未暴露”，不得猜测。
- 不使用 Python、SVG 路径脚本或程序化绘图生成流体装饰位图。

以下对象必须保持可编辑：标题、正文、编号、图标、线条、圆环、进度条、流程连接线、指标数字、业务图片槽、封面标题框和章节细框。

## 6. 三页技术探针

扩展完整库存前，先完成以下三页：

| 探针 | 页面 ID | 必须验证 |
|---|---|---|
| 封面 | `cover-marble-frame` | JSON 导入、标题编辑、标题框、装饰锁定、PPTX 往返 |
| 四项正文 | `content-text-4` | 四项密度、长标题、正文容量、顺序和分页 |
| 单图文 | `content-image-1` | 横图、竖图、方图裁切、图片替换、装饰保护 |

三页必须满足：

- 能导入编辑器并正确显示。
- 标题和正文可编辑，保存重载后仍存在。
- 内容图片可替换，固定装饰不会被替换。
- 横图、竖图和方图裁切稳定。
- 四项页面不会因标题过长退化为四张单项页。
- PPTX 导出后可以被项目同款解析器重新导入。

探针未通过前不得扩展 MVP。公共能力不足时，自动增加固定数据失败测试，再做最小修复和受影响回归，不等待用户确认。

## 7. 模板语义和渲染规则

### 7.1 元素语义

| 字段 | 规则 |
|---|---|
| `type` | `cover`、`contents`、`transition`、`content`、`end` |
| `textType: "title"` | 页面主标题 |
| `textType: "content"` | 页面正文或副标题 |
| `textType: "item"` | 目录项或列表项正文 |
| `textType: "itemTitle"` | 内容项标题 |
| `textType: "itemNumber"` | 内容项编号或指标编号 |
| `textType: "partNumber"` | 章节编号 |
| `groupId` | 绑定同一内容项的编号、标题、正文和图片 |
| `imageType: "decoration"` | 固定背景和装饰，默认锁定 |
| `imageType: "content"` | 可替换的业务图片 |
| `allowedItemCounts` | 页面允许的精确项目数量 |
| `sourceTitle` | 保存原始标题 |

### 7.2 图片规则

- Agent 图片只能进入 `imageType: "content"` 的业务图片槽。
- 固定背景和流纹装饰标记为 `imageType: "decoration"` 并锁定。
- 内容图片记录原始宽高，横图、竖图和方图统一使用稳定的 `cover` 裁切。
- 单图文版式只接收一张业务图片，多余图片返回明确错误。
- 无图输入不显示空业务图片框。
- 图片缺少原始尺寸时返回明确错误。

### 7.3 选版和分页规则

- 目录 2、3、4、5、6、10 项精确匹配对应版式。
- 其他目录数量平衡分页，保持项目顺序。
- 无图正文 1～4 项精确匹配对应版式。
- 超过 4 项时按容量无损分页，保持标题和正文关系。
- 单图文长正文分页时，业务图片只保留在首段，后续页使用无图版式。
- 四指标页面只在输入满足指标契约时可达。
- 行动结束页支持 0～3 项行动信息，超过上限返回明确错误。
- 页面增长策略建议初始值为 `factor: 1.75`、`slack: 5`。

### 7.4 标题保真规则

- 原始标题完整保存到 `sourceTitle`。
- 显示标题适配时不能直接截断或丢弃信息。
- 标题适配和正文分页分别计算。
- 四项页面不能因为标题过长退化为四张单项页。
- 普通标题过长和异常分页膨胀使用不同错误码和测试用例。

| G8 | 冻结候选版本并完成正式 QA | 测试、截图、PPTX、回环摘要、QA 报告 | 当前候选版本全部自动验收通过 |

## 9. 测试和验收

### 9.1 开发阶段

使用固定数据、Fake/Mock 和隔离环境，不调用真实内容模型。

专项测试至少覆盖：

- 12 页 MVP、18 页生产库存和全局唯一 ID。
- 构建器连续两次输出相同 JSON。
- 五种页面类型和目录 2/3/4/5/6/10 项选版。
- 正文 1/2/3/4 项选版、超量分页和项目顺序保持。
- `sourceTitle`、长标题和四项页面密度。
- 单图文横图、竖图、方图裁切和图片替换。
- 无图输入不显示空图片槽。
- `content` 图片和 `decoration` 图片严格隔离。
- 资源路径存在，JSON 不含 Base64 大图和本机绝对路径。
- 音频、动画、切换、版权文字和源媒体不进入生产资源。
- 模板选择器、注册项、资源接口和 PPTX 往返验证器一致。

### 9.2 G8 正式 QA

候选版本冻结后一次性执行：

- 模板专项测试和受影响公共回归。
- 真实 Worker 生成五种页面类型。
- 标题、正文编辑，保存重载，内容图片替换。
- 固定装饰保持不变，导出失败提供反馈和重试。
- PPTX 导出并重新导入。
- 代表页面全尺寸视觉检查。
- 1920×1080、1366×768、768×1024、390×844 四视口验收。

开发阶段使用临时证据。候选版本冻结后再生成正式截图、编辑换图、四视口、真实生成和 PPTX 往返证据。文件发生变化后按影响范围重验：视觉位置调整检查受影响页面，图片槽或裁切调整重验换图和 PPTX 往返，公共渲染器修改才运行全部模板回归。

## 11. 主要风险

| 风险 | 处理 |
|---|---|
| 源媒体授权不明 | 排除源媒体，使用原创或授权明确素材 |
| 缺少项目语义占位符 | 重建页面类型、文字槽、图片槽和稳定 ID |
| 流纹过密影响阅读 | 普通内容页保持至少 70% 低干扰区 |
| PNG 体积过大 | 背景用 JPEG，透明素材按体积门禁压缩 |
| 图片和装饰误替换 | 严格区分 `content` 和 `decoration` |
| 标题过长导致分页膨胀 | 使用 `sourceTitle`，分离标题适配和正文分页 |
| V2 信息图提前进入 V1 | 时间轴、十柱对比、SWOT 和三步流程单独规划 |
