## 2. 背景、目标与范围

### 2.1 背景

项目已经支持根据 AI 生成的语义数据填充 PPTist 模板。模板负责提供页面风格、文字槽位、图片槽位和元素坐标，渲染器负责选择版式、替换内容、拆分页和输出作品。

现有年会 PPT 只能作为视觉参考，不能原样上线。原文件体积较大，包含音频、高分辨率图片、第三方版权声明、示例公司信息和不稳定字体，也没有完成项目要求的页面及槽位标注。

### 2.2 开发目标

开发完成后，用户可以在模板列表中选择“红金年会颁奖”，生成一套视觉统一、文字可编辑、图片可替换、可以正常导出 PPTX 的年会演示文稿。

V1 必须实现：

1. 支持 `cover`、`contents`、`transition`、`content`、`end` 五种页面。
2. 目录支持 2、3、4、5、6、10 项。
3. 内容页支持 2、3、4 项内容。
4. 支持 0～3 张内容图片。
5. 长正文和超量内容可以拆页，不允许静默丢失。
6. 装饰图片不能被 AI 配图替换。
7. 模板可以在编辑器中继续编辑并导出 PPTX。

### 2.3 本期包含

- 制定红金视觉规范。
- 重新生产可授权的装饰素材。
- 制作模板页面并完成 PPTist 标注。
- 导出并整理 `template_7.json`。
- 外置和压缩模板图片资源。
- 注册后端模板列表。
- 补充模板渲染测试。
- 完成桌面、平板、手机预览检查。
- 验证生成、编辑和导出流程。

### 2.4 本期不包含

- 音频、视频和复杂动画。
- 图表专用版式。
- 4:3、16:10 等其他比例。
- 多套颜色主题切换。
- 在线模板配置后台。
- 自动把任意 PPT 转换成可用模板。
- 真实员工照片、公司 Logo 和真实奖项数据。

## 3. 关键决策与待确认事项

### 3.1 已确定的开发原则

| 决策 | 说明 |
|---|---|
| 使用 `template_7` | `template_6` 当前预留给图表模板，避免编号冲突 |
| 只支持 16:9 | V1 不处理其他页面比例 |
| 原 PPT 只作参考 | 未确认授权的素材不能直接进入生产模板 |
| 装饰与内容分离 | 只有内容图片可以被 AI 替换 |
| 图片资源外置 | 模板 JSON 不重复嵌入大型 Base64 图片 |
| 优先不改渲染器 | 先通过模板结构解决装饰图片误替换问题 |
| 先做 12 页 MVP | 验证链路后再扩展到 22 页生产版 |

### 3.2 开发前必须确认

1. 原始 PPT 是否具有商业使用和再分发授权。
2. 最终素材采用人工设计、AI 生成还是两者结合。
3. 是否保留灯笼、祥云等中国风元素。
4. 是否去除生肖元素，使模板可以跨年份使用。
5. 是否需要公司 Logo 槽位。
6. 最终模板资源体积上限。
7. V1 是内部使用还是对外商业发布。

版权状态未确认前，可以进行结构设计和原创素材制作，但不能将原模板素材作为生产资源发布。

## 5. 技术方案与系统约束

### 5.1 现有接口

后端模板列表接口返回模板名称、ID 和封面地址。模板资源通过 `/api/data/{filename}` 读取。

计划注册的数据为：

| 字段 | 值 |
|---|---|
| `name` | 红金年会颁奖 |
| `id` | `template_7` |
| `cover` | `/api/data/template_7.jpg` |

模板文件由渲染器从以下路径加载：

```text
backend/main_api/template/{template_id}.json
```

模板 ID 必须匹配：

```text
template_[1-9][0-9]*
```

### 5.2 页面类型

项目支持以下页面类型，详细数据结构见 [`PPT_Structure.md`](./PPT_Structure.md)。

| 页面类型 | 用途 | 关键数据 |
|---|---|---|
| `cover` | 封面 | `title`、可选 `text` |
| `contents` | 目录 | `items` |
| `transition` | 章节过渡 | `title`、可选 `text` |
| `content` | 内容 | `title`、`items` |
| `end` | 结束页 | 可无 `data` |

### 5.3 版式选择规则

开发模板页面时必须理解以下规则：

- 封面、章节和结束页默认使用同类页面的首个版式。
- 目录页根据 `item` 槽位数量选择容量最接近的版式。
- 内容页根据 `item` 槽位数量选择容量最接近的版式。
- 有 AI 配图时，渲染器优先选择包含图片节点的内容版式。
- 内容项目超过模板最大槽位数时，渲染器自动拆页。
- 长正文超过可读容量时，渲染器拆分内容并生成“（续）”页。

因此，目录页必须提供准确的 2、3、4、5、6、10 项槽位，内容页必须至少提供 2、3、4 项槽位。

### 5.4 图片替换风险

当前渲染器会按页面中图片元素的顺序填入 AI 配图。它不会自动区分奖杯、灯笼等装饰图片和人物、活动等内容图片。

V1 采用以下规则避免误替换：

1. 不可替换的装饰优先合并进页面背景。
2. 简单装饰可以使用普通形状表达。
3. 页面中的普通图片节点只保留真实内容图片槽。
4. 人物照片、团队照片、活动照片必须使用独立图片槽。
5. 图片槽顺序必须与预期填图顺序一致。

如果以上方案无法满足设计要求，再单独规划图片角色字段和渲染器改造，不在 V1 中临时加入未验证字段。

### 5.5 接入流程

```text
版权与视觉确认
   ↓
生产原创装饰素材
   ↓
制作 12 页 MVP 模板
   ↓
标注页面类型和内容槽位
   ↓
导出模板 JSON
   ↓
外置并压缩图片资源
   ↓
注册 template_7
   ↓
运行测试数据并检查结果
   ↓
扩展到 22 页生产版
   ↓
完成端到端验收
```

模板导入、标注和导出操作见 [`Template.md`](./Template.md)。

## 6. 页面版式规划

### 6.1 MVP 页面

MVP 共 12 页，是项目要求的最小可用模板。

| 类型 | 数量 | 版式要求 |
|---|---:|---|
| 封面 | 1 | 主标题、副标题 |
| 目录 | 6 | 分别支持 2、3、4、5、6、10 项 |
| 章节过渡 | 1 | 章节编号、标题、说明 |
| 内容 | 3 | 分别支持 2、3、4 项 |
| 结束 | 1 | 标题、可选说明 |
| 合计 | 12 | 完成生成链路验证 |

### 6.2 生产版页面

MVP 验证通过后扩展到 22 页，减少生成结果的重复感。

| 类型 | 数量 | 生产版新增内容 |
|---|---:|---|
| 封面 | 2 | 增加简洁红金封面 |
| 目录 | 6 | 沿用 MVP 目录页 |
| 章节过渡 | 4 | 帷幕、圆框、红毯、灯笼四种构图 |
| 内容 | 8 | 增加单项、图文、人物、数字版式 |
| 结束 | 2 | 正式落幕和简洁致谢 |
| 合计 | 22 | 生产版模板库 |

### 6.3 内容版式矩阵

| 版式 | `item` 数量 | 内容图片 | 布局 |
|---|---:|---:|---|
| 双栏内容 | 2 | 0 | 左右双栏 |
| 三项内容 | 3 | 0 | 三列或三段式 |
| 四项内容 | 4 | 0 | 四项均分 |
| 单项图文 | 1 | 1 | 左文右图或左图右文 |
| 双图文 | 2 | 2 | 两组图文 |
| 三人物 | 3 | 3 | 三张人物照片 |
| 年度数字 | 1～4 | 0 | 大数字和简短说明 |
| 单项结论 | 1 | 0 | 一条重点结论 |

每个版式只承担一种主要布局职责。不要为了复用而把过多文字、图片和装饰塞进同一页面。

## 7. 视觉与资源规范

### 7.1 色彩和字体

| 用途 | 规范 |
|---|---|
| 主色 | 深红、正红 |
| 背景 | 炭黑或深蓝黑 |
| 强调色 | 暖金、暗金 |
| 主文字 | 白色或浅金色 |
| 次级文字 | 暖灰色 |
| 中文字体 | 微软雅黑或项目统一字体 |
| 英文数字 | Arial 或项目统一无衬线字体 |

禁止使用来源不明的商业艺术字体。不能依赖只有设计人员电脑安装的字体。

字号建议：

- 封面标题不小于 50pt。
- 页面标题不小于 35pt。
- 内容标题不小于 24pt。
- 正文不小于 16pt。

### 7.2 排版规则

- 页面保持一致的左右安全边距。
- 页面标题尽量保持单行，最长不超过两行。
- 帷幕、灯笼、奖杯和粒子不能遮挡正文。
- 图片裁剪比例保持稳定，不能拉伸变形。
- 同类页面的标题、编号和页码位置保持一致。
- 正文过长时拆页，不能无限缩小字号。
- 标题、正文、编号、姓名和年份不能写进背景图。

### 7.3 V1 核心素材

| 资源 | 建议尺寸 | 格式 | 用途 |
|---|---:|---|---|
| 主舞台背景 | 1920×1080 | JPG | 封面 |
| 深色内容背景 | 1920×1080 | JPG | 内容页 |
| 章节背景 | 1920×1080 | JPG | 过渡页 |
| 落幕背景 | 1920×1080 | JPG | 结束页 |
| 红色帷幕 | 1920×1080 | 透明 PNG | 舞台装饰 |
| 舞台底部 | 1920×450 | 透明 PNG | 红毯、台阶或云浪 |
| 红金灯笼 | 800×800 | 透明 PNG | 年会装饰 |
| 金色奖杯 | 1000×1000 | 透明 PNG | 颁奖装饰 |
| 金色桂冠 | 1000×700 | 透明 PNG | 荣誉装饰 |
| 空白标题框 | 1600×700 | 透明 PNG | 标题背景，不含文字 |
| 聚光灯 | 1920×1080 | 透明 PNG | 氛围叠加 |
| 单人相框 | 900×1100 | 透明 PNG | 人物照片装饰 |

完整可选素材见附录 A。MVP 阶段不需要先生产所有可选装饰。

### 7.4 图片规则

- 不包含第三方水印、未经授权的 Logo 或真实人物。
- 不包含固定标题、年份、公司名和奖项名称。
- 全屏不透明背景使用 JPG，透明装饰使用 PNG。
- 透明 PNG 必须具有真实 Alpha 通道。
- 左右对称元素优先通过翻转复用。
- 保存原始文件、压缩文件、提示词和授权记录。
- 同一图片不能重复以 Base64 形式写入模板 JSON。

### 7.5 命名规则

统一格式：

```text
template_7_asset_{category}_{name}_v{version}.{ext}
```

示例：

```text
template_7_asset_bg_cover_v1.jpg
template_7_asset_stage_curtain_v1.png
template_7_asset_award_trophy_v1.png
template_7_asset_people_frame_single_v1.png
```

文件名使用小写英文、数字和下划线，不使用空格和中文。

## 8. 模板标注与槽位约定

### 8.1 槽位表

| 页面类型 | 槽位 | 数量 | 必填 |
|---|---|---:|---|
| `cover` | `title` | 1 | 是 |
| `cover` | `content` | 1 | 否 |
| `contents` | `item` | 2～10 | 是 |
| `contents` | `itemNumber` | 与目录项一致 | 否 |
| `transition` | `partNumber` | 1 | 否 |
| `transition` | `title` | 1 | 是 |
| `transition` | `content` | 1 | 否 |
| `content` | `title` | 1 | 是 |
| `content` | `itemTitle` | 1～4 | 否 |
| `content` | `item` | 1～4 | 是 |
| `content` | `itemNumber` | 1～4 | 否 |
| `content` | 内容图片 | 0～3 | 否 |
| `end` | `title` | 1 | 否 |
| `end` | `content` | 1 | 否 |

### 8.2 标注要求

1. 每页必须标注正确的页面类型。
2. 每个动态文字必须标注对应槽位。
3. 同一内容项的标题、正文、编号和装饰应放在同一分组。
4. 空项目被删除时，其编号、边框和项目装饰应一起删除。
5. 目录页的槽位数必须与其目标容量一致。
6. 内容图片槽不能与奖杯、灯笼等装饰图片混用。
7. 图片槽顺序必须稳定，并记录在模板检查表中。
8. 装饰图片中不能包含需要动态替换的业务文字。

### 8.3 标注完成检查

- 页面类型是否正确。
- 标题、正文和列表项是否均有槽位。
- 编号槽位是否与项目数量一致。
- 空槽清理是否会连带删除正确分组。
- 内容图片是否可以独立替换。
- 装饰图片是否保持不变。
- 导出的 JSON 是否仍保持 16:9 画布。

## 10. 测试与验收

### 10.1 必测场景

| 场景 | 输入 | 预期结果 |
|---|---|---|
| 短封面标题 | 8 字以内 | 标题保持单行 |
| 长封面标题 | 约 20 字 | 最多两行且不溢出 |
| 目录容量 | 2、3、4、5、6、10 项 | 选择对应目录版式 |
| 内容容量 | 2、3、4 项 | 选择对应内容版式 |
| 超量内容 | 8 项 | 自动拆成多页，顺序不变 |
| 长正文 | 单项超过正常容量 | 自动拆分，不丢字 |
| 无图片 | 0 张 | 不出现破损图片 |
| 单图 | 1 张横图或竖图 | 正确裁剪且不变形 |
| 多图 | 2～3 张 | 按图片槽顺序填充 |
| 装饰保护 | 带 AI 配图的页面 | 奖杯、灯笼、背景不被替换 |
| 结束页 | 无 `data` | 页面仍能渲染 |
| 导出 | 完整生成作品 | PPTX 可下载并重新打开 |

完整测试数据矩阵见附录 B。

### 10.2 功能验收

- 模板列表显示“红金年会颁奖”。
- 模板封面加载成功并具有选中反馈。
- AI 生成流程可以使用 `template_7`。
- 五种页面类型均可正常渲染。
- 目录和内容页能够按项目数量选择版式。
- 超量内容可以分页，长正文不会静默截断。
- 内容图片进入正确槽位，装饰图片保持不变。
- 编辑器可以继续编辑生成结果。
- PPTX 可以正常导出并重新打开。

### 10.3 视觉验收

- 所有页面保持统一的红、黑、金视觉。
- 标题、正文和编号不被装饰遮挡。
- 标题没有意外换行，正文没有溢出。
- 图片裁剪正常，不拉伸、不变形。
- 人物照片、相框、姓名和职位保持独立分层。
- 不存在水印、示例公司、固定年份和操作说明。
- 不存在不可用字体或明显字体替换。

### 10.4 性能验收

以下数值作为 V1 建议目标，最终以实际测试基线为准：

| 指标 | 建议目标 |
|---|---:|
| `template_7.json` | 小于 1 MB |
| 全部外置素材 | 小于 10～15 MB |
| 单张背景 | 小于 800 KB |
| 单张透明装饰 | 小于 1 MB |
| 模板封面 | 小于 150 KB |

模板不能包含 WAV 音频、WDP 图片、未引用资源或重复 Base64 大图。生成 20 页作品时，浏览器不能崩溃或出现明显失去响应。

### 10.5 版权验收

- 每张生产素材均有来源记录。
- 第三方素材具备项目所需授权。
- 不直接复制未授权的原模板装饰。
- 不使用未经授权的 Logo 和人物照片。
- AI 生成素材保留提示词和生成记录。

版权验收未通过时，模板不得进入生产环境。

## 11. 里程碑与排期

| 里程碑 | 交付内容 | 预计时间 | 通过条件 |
|---|---|---:|---|
| M1 视觉样板 | 6 页样板、4 张背景、8 张核心装饰 | 2～3 天 | 视觉、版权和图片槽方案确认 |
| M2 MVP 模板 | 12 页、JSON、外置资源、封面 | 3～4 天 | 五种页面生成链路通过 |
| M3 生产版 | 22 页、自动化测试、QA 记录 | 3～6 天 | 功能、视觉、性能、版权验收通过 |

总工作量预计为 8～13 个工作日。版权确认和视觉样板是后续工作的前置条件，未通过时不进入生产版模板制作。

## 12. 风险、发布与回滚

### 12.1 主要风险

| 风险 | 影响 | 处理方式 |
|---|---|---|
| 素材版权不明确 | 模板无法上线 | 使用重新生产的原创素材 |
| 装饰图片被替换 | 页面视觉损坏 | 合并背景或改用形状 |
| 资源体积过大 | 加载慢、浏览器崩溃 | 图片外置、压缩、删除音频 |
| 目录或内容槽位不足 | 内容错位或频繁分页 | 按容量制作准确版式 |
| 字体不可用 | 换行和版式变化 | 使用项目统一字体 |
| 图片比例不一致 | 图片变形 | 固定裁剪框和比例 |

### 12.2 发布前检查

- `template_7` 未覆盖其他模板。
- `/templates` 返回正确的名称、ID 和封面。
- 所有模板资源地址返回成功。
- 一套完整测试数据已经生成并逐页检查。
- 导出的 PPTX 已重新打开检查。
- 桌面、平板和手机代表尺寸已完成预览检查。
- 功能、视觉、性能和版权验收全部通过。

### 12.3 回滚条件

出现以下任一情况时，应从模板列表暂时移除 `template_7`：

- 模板 JSON 无法加载。
- 大量图片资源无法访问。
- 生成内容频繁错位或丢失。
- 装饰图片被 AI 配图替换。
- PPTX 无法导出或重新打开。
- 发现未解决的版权问题。

回滚只移除模板入口，不删除用户已经生成的作品。修复并重新完成验收后再恢复模板。

## 附录 C：设备适配检查

PPT 画布保持固定 16:9。模板选择、预览和编辑界面应检查以下代表尺寸：

| 设备 | 代表尺寸 | 检查重点 |
|---|---:|---|
| 普通桌面 | 1366×768 | 模板列表、编辑器布局、导出入口 |
| 高分桌面 | 1920×1080 | 画布清晰度和留白 |
| 平板 | 768×1024 | 卡片滚动、预览比例、按钮尺寸 |
| 手机 | 390×844 | 缩略图、横屏预览、页面溢出 |

所有可见按钮必须有点击反馈。模板加载、生成、图片替换、导出和重试入口不能点击无响应。
