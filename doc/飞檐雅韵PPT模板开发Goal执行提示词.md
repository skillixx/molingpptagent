九、PPTist 语义协议
- 页面类型只使用 cover、contents、transition、content、end。
- 文字槽使用 title、content、item、itemTitle、itemNumber、partNumber。
- 同一内容组的编号、标题、正文、内容图和关联形状使用稳定 groupId。
- 内容不足时删除整个未使用组，不留下孤立编号、连线或卡片。
- 可替换业务图片使用 imageType: content。
- 背景和固定装饰使用 imageType: decoration。
- 内容图片携带原始宽高，并验证横图、竖图和方图裁切。
- 图片通过 /api/data/<filename> 引用，JSON 不内嵌 Base64 大图。
- 生产 JSON 不包含音频、动画、视频和原生 chart。

十四、自动决策规则

- 视觉样稿在开发说明边界内由执行者自动选择最佳方案，不设置样稿人工评审门禁。
- 普通测试失败、裁切错误、文本溢出和局部兼容问题自动定位、修复并重新验证。
- 未获授权的提交、推送、部署和生产动作保持不执行，不阻塞模板 Goal 达到 READY_FOR_CONFIRMATION。

十五、阻断规则
- 普通测试失败、素材效果不佳、版式溢出和局部兼容问题不构成阻断。
- 缺少必须由用户提供的授权素材或业务信息时，先完成其他不受影响工作。
- 需要不可逆操作、外部写入、生产动作或无关架构改造时暂停并请求授权。
- 只有同一阻断连续出现至少三个 Goal 回合，安全替代方案已耗尽，且没有其他范围内工作可继续时，才标记 blocked。

十六、最终状态规则

- 必须完成真实生成、编辑、换图、失败重试、四视口、PPTX 导出和重新导入。
- 必须保存素材来源、提示词、实际模型、截图、测试结果、失败记录和已知限制。
