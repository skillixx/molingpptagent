# 科技蓝扁平 PPT 模板开发说明

## 1. 文档信息与开发目标

| 项目 | 内容 |
|---|---|
| 模板名称 | 科技蓝扁平 |
| 建议模板 ID | `template_8` |
| 参考 PPT | `C:\Users\sk20\Desktop\扁平风格(38).pptx` |
| 项目目录 | `D:\moling\TrainPPTAgent` |
| 页面比例 | 16:9 |
| 逻辑画布 | 1000 × 562.5 |
| 当前状态 | `DONE`，自动验收通过，用户已于 2026-08-24 确认闭合 |

本任务要把参考 PPT 转换成 TrainPPTAgent 可选择、可生成、可编辑、可导出和可回归测试的生产模板。

最终模板必须具备以下能力：

1. 模板选择页显示“科技蓝扁平”及其封面。
2. 能生成封面、目录、章节、内容和结束页。
3. 目录支持 2、3、4、5、6、10 项。
4. 内容页支持 1～4 项，超量或超长内容自动分页。
5. 内容图片可以替换，背景和装饰图片不会被 AI 替换。
6. 用户可以编辑生成结果，并导出、重新导入 PPTX。
7. 桌面、平板和手机端不溢出，所有操作按钮都有反馈。

### 2.1 本次要做

- 盘点参考 PPT 的 27 个页面，选择可复用版式。
- 清理示例文字、模板来源标识、非标准字体和未授权图片。
- 统一颜色、字体、字号、边距和装饰规则。
- 生产必要的原创背景和透明装饰。

- 导出并整理 `template_8.json` 和 `template_8.jpg`。
- 注册模板列表，补充模板专项测试。
- 验证生成、编辑、图片替换、设备适配和 PPTX 导出。
- 完成素材来源与 QA 记录；自动验收通过后提交用户确认。

### 2.2 本次不做

- 不重写 PPTist 编辑器，也不开发新的图表引擎。
- 不修改 AI 大纲协议，除非测试证明现有协议无法满足基础页面。
- 不直接使用授权不明确的照片、字体、Logo或模板来源标识。
- 不生成伪造的产品界面、证书、业务数据、真实人物或事实证据。
- 不主动提交、推送或部署，除非用户另行授权。

## 3. 参考模板与页面映射

参考文件名包含“38”，实际有 27 页。文件为 16:9，包含 1 个母版和 6 个版式。

| 参考页 | 候选用途 | 开发处理 |
|---|---|---|
| 第 1 页 | 封面 | 保留构图，替换字体、文案和版权装饰 |
| 第 2 页 | 目录 | 改造成不同目录容量的版式 |
| 第 3、9、15、22 页 | 章节 | 精选 2 个稳定构图，其余不进入生产版 |
| 第 4～8 页 | 内容 | 选择两项、三项、四项和指标候选 |
| 第 10～14 页 | 内容 | 选择流程、对比或图文候选 |
| 第 16～21 页 | 内容 | 选择单结论、双栏和图文候选 |
| 第 23～26 页 | 内容 | 选择单图文、双图文或补充版式 |
| 第 27 页 | 结束 | 保留构图，替换示例文字 |

参考 PPT 主要由普通形状和组合对象构成，不能依赖原生 PowerPoint 占位符自动生成内容。

开发者必须把选中的页面导入 PPTist，并在 JSON 中重新标注页面类型和语义槽位。没有清晰内容槽的页面不得进入生产模板。

## 5. 视觉与素材规范

### 5.1 颜色

| 用途 | 色值 |
|---|---|
| 深色主背景 | `#17191D` |
| 深蓝辅助背景 | `#21354A` |
| 主强调色 | `#45BEE3` |
| 次强调色 | `#25A6CD` |
| 浅色背景 | `#F4F6F8` |
| 主文字 | `#222B35` |
| 次文字 | `#6B7280` |
| 反白文字 | `#FFFFFF` |

主视觉只使用深蓝、青色和白色。红色不作为常规装饰色，只有真实警示或负向数据才可以使用。

### 5.2 字体和字号

- 中文统一使用微软雅黑，或项目确认可部署的思源黑体。
- 英文和数字统一使用 Arial，或与中文使用同一字体。
- 不依赖“时尚中黑简体”“汉仪大宋简”“方正兰亭刊黑_GBK”“Nexa Bold”等字体。
- 封面标题不低于 50px。
- 页面标题不低于 35px。
- 内容项标题不低于 24px。
- 正文不低于 16px。
- 自动缩字不得低于 12px；仍放不下时必须拆页，不能截断正文。

### 5.3 页面安全区

- 画布固定为 1000 × 562.5。
- 默认左右边距保持一致。
- 内容页中央 75% 保持低干扰。
- 封面至少保留 55% 的连续标题区域。
- 章节装饰集中在一侧，另一侧用于章节标题。
- 装饰不能进入正文、图表或内容图片槽。
- 单行页面标题不能因为替换文案变成两行。
- 图片框要分别验证横图、竖图和方图的裁剪效果。

### 5.4 哪些元素保留为形状

以下内容使用 PPTist 形状，不制作位图：

- 三角形、多边形和规则色块。
- 斜线、分隔线、时间轴和连接线。
- 圆形、圆环、步骤节点和序号块。
- 内容卡片、图片蒙版、半透明遮罩和常规阴影。
- 页码、章节数字和普通粒子圆点。

这些元素保留为形状，便于换色、缩放和编辑，也能控制模板和导出文件体积。

### 5.5 必要位图素材

首版只生产必要素材，不固定内置城市或科技内容照片。内容图片由生成时的候选图片池提供。

模板需要的背景和透明装饰允许使用 GPT Image 2（`gpt-image-2`）生成。每种素材必须使用独立提示词，不能一次生成难以裁切和复用的素材拼图。

| 文件名 | 格式 | 用途 | 要求 |
|---|---|---|---|
| `template_8_asset_bg_dark_v1.jpg` | JPG | 封面、章节、结束页共用深色背景 | 1920×1080，中央低干扰，小于 300KB |
| `template_8_asset_network_mesh_v1.png` | PNG RGBA | 页面边缘网络装饰 | 真透明，只占边缘，小于 1MB |
| `template_8_asset_tech_glow_v1.png` | PNG RGBA | 局部青色光晕 | 无矩形底，不压文字，小于 1MB |
| `template_8_asset_city_silhouette_v1.png` | PNG RGBA，可选 | 图文或章节边缘装饰 | 泛化城市，无广告、文字和真实标识 |

浅色内容页优先使用纯色背景，不额外生产背景图片。

所有新素材必须原创或具有明确授权，并满足：无文字、无数字、无 Logo、无水印、无固定年份、无真实产品界面。

使用 GPT Image 2 时，必须保存最终提示词、模型名称、原始输出位置、项目发布路径和人工检查结果。发布素材必须复制到 `backend/main_api/template/`，不能只保留在图片工具的默认输出目录。

位图装饰不得使用 Python 或程序化绘图替代图片生成。规则多边形、线条、圆环和卡片等简单元素仍使用 PPTist 可编辑形状。

透明素材必须检查 Alpha 通道。白底、棋盘格或带矩形边缘的图片不能作为透明装饰使用。

## 6. PPTist 标注规范

### 6.1 页面类型

每个页面必须且只能标注为以下一种类型：

- `cover`
- `contents`
- `transition`
- `content`
- `end`

首版不使用 `reference`。以后增加参考资料页时，再确认前后端数据链路和测试覆盖。

### 6.2 文字槽位

| `textType` | 用途 |
|---|---|
| `title` | 页面主标题 |
| `content` | 封面副标题、章节说明或长正文 |
| `item` | 目录项或内容项正文 |
| `itemTitle` | 内容项标题 |
| `itemNumber` | 目录项或内容项编号 |
| `partNumber` | 章节编号 |
| `subtitle` | 图片说明或次级标题 |

同一内容组中的 `itemNumber`、`itemTitle`、`item` 和对应形状使用相同 `groupId`。

内容项不足时，渲染器应删除整个未使用组，不能只删除正文并留下编号或装饰。

### 6.3 图片槽位

- 可由 AI 或用户替换的图片使用 `imageType: "content"`。
- 背景和装饰图片使用 `imageType: "decoration"`。
- 内容图片不得与背景、装饰或文字合成一个不可拆分的大组。
- 装饰图片锁定，内容图片保持可选中。
- 用户选中内容图片后必须看到“替换图片”入口和操作反馈。
- 没有输入图片时，不得留下破图或空白图片框。

## 7. 模板数据与代码接入

### 7.1 `template_8.json` 要求

- 路径为 `backend/main_api/template/template_8.json`。
- 模板 ID 为 `template_8`。
- 画布为 1000 × 562.5。
- MVP 的 12 个页面 ID 写入 `metadata.mvpSlideIds`。
- 页面 ID 和元素 ID 全部唯一。
- 图片使用 `/api/data/` 地址，不内嵌 Base64 大图。
- JSON 文件小于 1MB，不引用缺失或未使用素材。
- 内容图片与装饰图片必须使用明确的 `content/decoration` 协议。

### 7.2 计划修改位置

| 文件 | 计划改动 |
|---|---|
| `backend/main_api/template/template_8.json` | 新增模板 JSON |
| `backend/main_api/template/template_8.jpg` | 新增模板列表封面 |
| `backend/main_api/template/template_8_asset_*` | 新增必要背景和装饰 |
| `backend/main_api/main.py` | 注册“科技蓝扁平”模板 |
| `backend/main_api/tests/test_template_8.py` | 新增模板专项测试 |

先验证现有渲染器。只有专项测试证明现有逻辑不足时，才修改 `template_renderer.py`。

不得为了 `template_8` 破坏 `template_1`～`template_7` 的生成结果。

如果后端模板列表已经能够驱动前端，不修改前端默认列表。只有实际启动或测试发现模板不可见时，才检查 `frontend/src/store/slides.ts`。

模板卡片、生成、失败重试、替换图片和导出按钮必须具备选中、加载、成功或失败反馈，不能点击后没有反应。

## 8. 开发任务与排期

### T1：版权和页面盘点，0.5天

任务：确认参考 PPT 授权范围，识别要替换的照片、字体和来源文字，完成 27 页候选映射。

完成条件：未授权内容都有替换或删除方案，MVP 和生产版候选页已确定。

### T2：视觉规范和素材，0.5～1天

任务：确定颜色、字体、字号和安全区；使用 GPT Image 2（`gpt-image-2`）或其他有明确授权的来源，生产深色背景和必要透明装饰。

完成条件：素材无文字、Logo和水印，透明通道有效，文件大小符合限制；提示词、模型、来源路径、发布路径和人工检查结果记录完整。

### T3：清理参考PPT并制作MVP，1天

任务：清理示例内容和非标准字体，拆分影响编辑的大组合，建立 12 页 MVP。

完成条件：页面可编辑，没有残留示例文案和未授权素材。

### T4：PPTist标注和JSON整理，1天

任务：标注页面、文字和图片类型，建立 `groupId`，导出并整理 `template_8.json`。

完成条件：MVP 能生成封面、目录、章节、内容和结束页，内容没有丢失。

### T5：生产版扩展，0.5～1天

任务：扩展到 18 页，补充封面、章节、单结论、图文和结束版式，生成 `template_8.jpg`。

完成条件：18 页均有明确用途、容量和语义槽位，没有重复或无法自动填充的页面。

### T6：代码接入和自动测试，0.5～1天

任务：注册模板，增加模板专项测试，必要时以兼容方式调整渲染器。

完成条件：模板资源返回正常，专项测试和现有回归测试通过。

### T7：端到端和设备QA，1天

任务：完成真实生成、文字编辑、图片替换、失败重试、PPTX导出和多设备检查。

完成条件：第9章全部验收项通过，逐页截图和导出物已保存。

### T8：记录和人工确认，0.5天

任务：创建素材与 QA 记录，写明素材来源、测试结果、截图、导出证据和已知限制。

完成条件：完成定义和自动验收清单全部满足后生成最终报告；用户明确确认后，模板开发才完成闭合。

总工期预计为 5～6 天。优先完成 12 页 MVP，验证链路后再扩展到 18 页。

## 9. 测试与验收

### 9.1 模板结构

- 模板 ID、画布尺寸和页面类型正确。
- MVP 为 12 页，生产版为 18 页。
- 目录包含 2、3、4、5、6、10 项版式。
- 内容包含 1、2、3、4 项容量，或通过单结论页覆盖 1 项。
- 页面 ID、元素 ID 唯一。
- JSON 不包含 Base64 大图，所有资源路径存在。

### 9.2 内容生成

- 封面标题、副标题填入正确槽位。
- 目录数量与输入数量一致，未使用目录组被完整删除。
- 章节标题、说明和章节编号正确。
- 1～4 项内容选择合适版式。
- 8 项内容能够分页，合并后顺序与输入一致。
- 超长正文不截断，不通过低于 12px 的字号勉强容纳。
- 缺少必要内容槽时显式失败，不能生成丢失正文的半成品。

### 9.3 图片替换

- 分别测试 0、1、2 张内容图片。
- AI 图片只进入 `imageType: "content"` 的槽位。
- 背景和装饰始终保留原资源地址。
- 空图片地址不占用图片槽。
- 内容图片可以被用户选中和替换。
- 替换后横图、竖图、方图裁剪正常。

### 9.4 视觉检查

- 逐页检查标题、正文、图片和装饰的重叠与越界。
- 不存在异常换行、文字裁切、破图、白边或拉伸。
- 页面标题保持单行，正文和图片具备清晰层级。
- 同类页面的颜色、字体、边距、标题位置保持一致。
- 不存在模板来源文字、第三方 Logo、水印和伪文字。

### 9.5 设备适配和交互

| 设备 | 视口 |
|---|---|
| 桌面 | 1920 × 1080 |
| 笔记本 | 1366 × 768 |
| 平板 | 768 × 1024 |
| 手机 | 390 × 844 |

- 四种视口无横向溢出和按钮遮挡。
- 模板卡片可选中，并显示明确选中状态。
- 生成时显示加载状态，失败后恢复为可重试。
- 替换图片、下载和导出操作都有可见反馈。
- 手机端模板列表可滚动，预览和下载入口可触达。

### 9.6 PPTX导出

- 导出的 PPTX 可以正常打开。
- 导出前后页面数量一致。
- 重新导入项目编辑器后，标题、正文和图片仍存在。
- 字体、换行、图片裁剪和装饰位置没有明显变化。
- 导出文件不包含破图、未填充占位符或异常空白页。

### 9.7 版权和资源

- 每个外部素材都有来源和授权记录。
- AI 生成素材保存最终提示词和生成记录。
- 不使用来源不明的字体、照片、Logo和水印。
- 不直接复用参考 PPT 中授权不明确的城市照片。
- 模板不包含可识别第三方品牌和真实人物。

## 10. 风险与相关资料

### 10.1 主要风险

| 风险 | 处理方式 |
|---|---|
| 参考模板版权不明确 | 只保留抽象版式关系，重新制作背景和装饰 |
| 非标准字体导致排版变化 | 使用项目可部署字体，导出后重新检查换行 |
| 大组合妨碍内容替换 | 拆分内容和装饰，只给语义元素设置槽位 |
| 装饰被 AI 图片覆盖 | 严格使用 `content/decoration` 图片协议和专项测试 |
| 相似版式过多导致随机不稳定 | 生产版只保留用途和容量明确的18页 |
