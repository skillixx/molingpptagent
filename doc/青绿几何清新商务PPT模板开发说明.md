## 2. 视觉规范

- 延续青蓝至薄荷绿的低多边形背景、白色文字、半透明卡片、细线边框和大号章节编号。
- 封面可以有较丰富的折面层次；正文背景更暗、更均匀，避免高亮三角形经过标题和正文阅读区。
- 装饰主要位于边缘和四角，不能遮挡标题、正文和业务图片主体。A5 花边按版式需要使用，不要求每页叠加。
- 中文优先使用微软雅黑，英文和数字优先使用 Arial；开发时核对编辑器及导出环境的实际字体可用性，不依赖原稿中的特殊字体才能完成基本阅读。
- 幻灯片保持 16:9，通过缩放适配屏幕，不因手机屏幕变窄而改变导出页面的内容顺序。受影响的模板选择、预览和编辑入口适配桌面、笔记本、平板和手机。
- 去除原稿固定的羊年图案、`201X/2015`、新年祝福和示例人物信息；正式内容由用户输入或在编辑器中修改。
- 以清晰、完整、可编辑和运行稳定为验收依据，不设置逐像素复刻或主观相似度门槛。

### 3.2 选版与内容容量

1. **封面与单图选版：**普通／长标题封面、左图／右图页面都要有可验证的选择方式。T1 在现有机制内确定触发条件和回退规则，并补充到本文，不能出现只有 JSON 中存在、实际无法使用的版式。
2. **目录：**按项目数量使用两至六项版式，超过六项按原顺序分页。单项或尾页单项复用已有容器，清理空槽，不增加虚假章节。
3. **正文：**按实际项目数选择一至四项版式；正文真正超出容量时有序分页，不丢项、不重复、不持续缩小字号来掩盖容量不足。
4. **长标题：**优先换行、调整区域或选择长标题版式。四项正文不能仅因项目标题过长变成四个单项页。确需改变展示标题时保留 `sourceTitle`，并在对应阅读位置完整展示原始标题，不允许截字。
5. **章节与团队：**原稿六张章节页共用一个过渡版式。四图页可用姓名作项目标题、职务或介绍作正文，不另增团队版式，也不补造人物信息。原稿使用说明页不进入库存。
6. **结束页：**结束语和补充信息保持在线编辑及导出可编辑，优先复用已有自动填充能力。若补充信息只能手动编辑，在 T1 和最终使用说明中明确，不为此擅自扩展通用协议。

### 4.2 素材使用要求

- A1～A5 不含文字、编号、日期、Logo、水印、业务图表或人物信息，不用整页截图代替可编辑页面；A3 中也不预制 `01`～`06`。
- A5 用于替代复杂花边，必须真实透明，无白底、黑边、棋盘格或明显裁切接缝。
- 记录素材来源、尺寸、格式和透明通道；在实际页面中检查清晰度、文字对比和遮挡，达到使用要求后停止迭代。
- 临时预览、生成中间稿和验收图片单独存放。业务图片使用用户内容或已有图片输入流程，不计入五张装饰，也不新增业务图片生成任务。

### 4.3 各类元素如何实现

| 对象 | 实现方式 | 替换与编辑规则 |
| --- | --- | --- |
| 标题、正文、编号、日期 | 原生文本，使用第 5.2 节的槽位标记 | 填充后仍可编辑，用户信息及顺序完整保留 |
| 卡片、边框、分隔线和简单标记 | 项目支持的原生形状、线条或文字 | 不烘焙到背景图片中 |
| 人物照片、案例图、产品图 | 图片元素，标记 `imageType: content` | 按项目绑定文字，保持顺序与比例，通过裁切适配，保留源尺寸和裁切信息 |
| A1～A5 背景与花纹 | 图片元素标记 `imageType: decoration`；原生背景字段保持背景角色 | 内容换图只处理业务槽位，不替换固定装饰 |

图片与文字通过当前项目的分组及关联机制绑定。缺图、读取失败、数量不匹配或容量不足时，使用明确错误或已约定且可验证的回退，不产生静默错配、虚假内容或无法解释的空白页。

### 5.2 内容字段与槽位

槽位是模板元素上的 `textType` 标记，填充器据此把输入文字放到对应位置。下表沿用现有协议；T1 对照当前实现确认具体映射，不新增平行业务协议。

| 页面 type | 输入内容 | 对应槽位与处理方式 |
| --- | --- | --- |
| `cover` | `data.title`、`data.text` | 主标题对应 `title`；副标题与已提供的汇报人、日期等合并到多行 `content`，不补造信息 |
| `contents` | `data.items` 中的章节名称 | 目录文字对应 `item`，编号对应 `itemNumber`；按第 3.2 节处理容量 |
| `transition` | `data.title`、可选 `data.text` | 对应 `title`、`content`；章节编号使用现有 `partNumber` 机制 |
| `content` | `data.title`、`data.items[].title`、`data.items[].text` | 对应 `title`、`itemTitle`、`item`；需要项目编号时使用 `itemNumber`，图片关联遵循第 4.3 节 |
| `end` | 当前结束页协议支持的输入 | 复用当前结束页填充方式；可编辑结束语和补充信息的边界见第 3.2 节 |

正文与四图团队介绍使用同一套项目结构。优先复用当前注册、选版、填充、分页、保存和导出实现；仅对实际影响本模板的缺口作最小修改，并补受影响验证。
