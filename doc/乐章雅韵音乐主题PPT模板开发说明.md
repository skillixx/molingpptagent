## 2. 视觉与交互规范

- 采用深咖黑底、白色或浅灰五线谱与音符、钢琴键盘和少量红色强调。封面装饰较丰富，目录与正文装饰集中于边缘，保留完整阅读区。
- 中文优先使用微软雅黑，英文和数字优先使用 Arial，检查编辑器与导出文件的实际显示。重点避免深色文字落在深色背景上，以及长数字意外断行。
- 标题、正文、编号、结束语、简单边框、分隔线和强调块使用可编辑原生元素；音乐背景和小提琴按第 4 节制作。
- 清理原稿示例标题、介绍、年份和作者推广信息；正式内容来自用户输入，不补造人物、单位、日期或数据。
- 模板选择、预览和编辑入口适配桌面、笔记本、平板与手机。幻灯片保持 16:9，通过缩放显示，不改变内容顺序。
- 本次新增或修改的按钮提供加载、成功、失败、重试或明确的假性交互反馈；生成、保存和导出按真实结果反馈。

### 3.2 选版、分页与内容完整性

1. **封面：**按实际字号和阅读区容量选择普通或长标题版式，优先换行与调整区域，不截字。T1 明确触发条件。
2. **目录：**按数量选择两至六项版式，超过六项按原顺序分页。单项及尾页单项复用容器并清理空槽，不补造章节；空目录沿用项目语义。
3. **正文：**按项目数选择一至四项版式，正文超出容量时有序分页，保留完整内容与原始顺序，不丢项、重复或持续缩小字号。
4. **长项目标题：**与正文分页分别处理。四项正文不能仅因项目标题长就拆成四个单项页；调整展示标题时保留 `sourceTitle`，并在对应阅读位置完整展示原始标题。
5. **单图与多图：**T1 明确左右单图的选版及回退规则；多图保持图片与项目文字的对应关系和顺序，裁切时保留比例、源尺寸与裁切信息。
6. **章节：**原稿四张章节页复用一个版式，编号动态填写；继承自原稿内部版式的页头也要改成可填充字段。
7. **结束页：**结束语与补充信息保持可编辑；T1 核定现有协议支持的自动填充范围，并记录需手动编辑的部分。

缺图、资源读取失败、图片数量不匹配或超出容量时，给出明确错误或采用已验证的回退；不得静默错配或丢失内容。所有版式都必须有正常流程中的选择方式，不能仅存在于 JSON。

### 3.3 内容字段与槽位

槽位是模板元素上的 `textType` 标记，填充器据此放入对应文字。沿用现有协议，T1 核定以下映射；业务图片绑定使用当前项目的关联机制。

| 页面 type | 输入内容 | 槽位或处理方式 |
| --- | --- | --- |
| `cover` | `data.title`、`data.text` | 主标题使用 `title`；副标题与用户提供的汇报信息使用多行 `content` |
| `contents` | `data.items` 中的章节名称 | 章节名称使用 `item`，编号使用 `itemNumber` |
| `transition` | `data.title`、可选 `data.text` | 使用 `title`、`content`，章节编号复用 `partNumber` |
| `content` | `data.title`、`data.items[].title`、`data.items[].text` | 使用 `title`、`itemTitle`、`item`，项目编号使用 `itemNumber` |
| `end` | 当前结束页协议支持的标题与补充信息 | 优先复用 `title`、`content`，具体边界在 T1 核定 |
| 业务图片 | 当前图片输入及关联字段 | 使用 `imageType: content`，保留顺序、关联和裁切信息 |

### 4.2 素材制作与使用规则

- **内容限制：**A1～A5 不带文字、编号、Logo、水印或业务数据。人物、课程、活动、作品照片走现有业务图片流程，不计入装饰素材。
- **角色标记：**装饰图片使用 `imageType: decoration`，业务图片使用 `imageType: content`；背景字段保持背景角色。A5 不占业务槽，换图不得覆盖固定装饰。
- **质量要求：**A5 真实透明、主体完整，无白底、黑边或棋盘格；全部素材在实际页面中清晰、不遮挡阅读区，对比度合适，合格后停止迭代。
- **资源记录：**保留来源、尺寸、格式、透明通道与用途，正式资源与测试文件分开存放。选择封面由最终页面渲染生成，不计入五张装饰图。
