## 2. 开发目标与范围

### 2.1 最终目标

模板完成后应具备以下能力：

- 模板选择页显示“AI 霓虹科技”和真实封面。
- 能生成封面、目录、章节、内容和结束页。
- 目录稳定支持 2、3、4、5、6、10 项。
- 内容页稳定支持 1、2、3、4 项。
- 超量、超长正文可以无损分页，不静默截断。
- Agent 配图只进入内容图片槽，不覆盖背景和装饰。
- 生成结果可以继续编辑、替换图片和导出 PPTX。
- 导出的 PPTX 可以重新导入项目继续编辑。
- 桌面、笔记本、平板和手机端没有横向溢出。
- 模板选择、生成、重试、图片替换和导出都有可见反馈。

### 3.3 保留与删除原则

保留以下视觉关系：

- 深海军蓝背景。
- 荧光青、冰蓝、紫色和少量粉色强调。
- 发光球体、粒子、光带和抽象科技氛围。
- 清晰的章节编号、大标题和内容分区。
- 能稳定承载两项、三项和四项数据的结构。

删除或重建以下内容：

- 3:1 超宽构图。
- 依赖特殊字体的文字效果。
- 来源不明的人物、照片、插画、Logo 和音频。
- 把英文字符拆成多个文本框的装饰方式。
- 固定示例数据和不可替换的嵌入图表。
- 投影环境下不可读的小字号和过细线条。

### 4.3 页面选择规则

- 目录按 `items` 数量匹配最接近且容量足够的目录页。
- 内容按 1、2、3、4 项匹配相同容量的内容页。
- 有 Agent 配图时优先选择图文页；无配图时优先选择纯文字页。
- 超过 4 项的内容由渲染器分页，不能挤入一个页面。
- 同一作品的封面、章节和结束页保持一致的主视觉，不随机造成风格漂移。

## 5. 视觉与核心素材规范

### 5.1 颜色

| 用途 | 色值 |
|---|---|
| 主背景 | `#050B24` |
| 次背景 | `#0B1740` |
| 荧光青 | `#00F6FF` |
| 冰蓝 | `#6CA2FF` |
| 霓虹紫 | `#A45CFF` |
| 霓虹粉 | `#FF70FF` |
| 主文字 | `#FFFFFF` |
| 次文字 | `#B9C6E4` |
| 浅色页深文字 | `#17213A` |

正文对比度优先于发光效果。霓虹粉只用于少量高光，不承担大段文字。

### 5.2 字体和字号

- 中文使用微软雅黑，或项目确认可部署、可商用的思源黑体。
- 英文和数字使用 Arial，或与中文统一为同一字体家族。
- 不使用“三极极黑简体”等未部署、未嵌入或授权不明确的字体。
- 封面标题建议 50～60px，不低于 50px。
- 页面标题建议 35～42px，不低于 35px。
- 内容项标题建议 22～26px。
- 正文建议 16～20px，不低于 16px。
- 自动适配绝对下限为 12px；仍放不下时必须拆页。

### 5.3 画布和安全区

- 画布固定为 1000 × 562.5。
- 左右安全边距建议 56～64。
- 顶部标题区建议 72～96 高。
- 底部安全距离不少于 28。
- 封面至少保留 50% 连续标题区域。
- 章节页至少保留 55% 连续标题和说明区域。
- 装饰集中在边缘或单侧，不能穿过正文和内容图片。
- 图文页分别验证横图、竖图和方图裁切。

### 5.4 哪些元素使用 PPTist 形状

以下元素使用可编辑形状，不制作成位图：

- 矩形、圆角矩形、圆形和简单圆环。
- 分隔线、编号块、页码和章节数字。
- 内容卡片、图片蒙版和半透明遮罩。
- 简单网格、步骤节点和连接线。
- 基础渐变色块和常规阴影。

## 6. PPTist 标注与数据映射

### 6.1 页面类型

每个页面必须且只能使用一种类型：

- `cover`
- `contents`
- `transition`
- `content`
- `end`

### 6.2 文字槽

| `textType` | 用途 |
|---|---|
| `title` | 页面主标题 |
| `content` | 封面副标题、章节说明或单结论正文 |
| `item` | 目录项或内容项正文 |
| `itemTitle` | 内容项标题 |
| `itemNumber` | 目录项或内容项编号 |
| `partNumber` | 章节编号 |
| `subtitle` | 图片说明或次级标题，只有真实需要时使用 |

同一内容项的 `itemNumber`、`itemTitle`、`item` 和伴随形状使用相同 `groupId`。

内容项不足时必须删除整个未使用分组，不能只删除正文并留下编号或装饰。

### 6.3 图片槽

- 可被 Agent 或用户替换的图片使用 `imageType: "content"`。
- 背景和固定装饰使用 `imageType: "decoration"`。
- 内容图片不得与标题、正文或固定装饰合成不可拆分的大组。
- 装饰图片默认锁定，内容图片保持可选中和可替换。
- 没有图片输入时优先选择纯文字页，不能留下破图或空图片框。

### 6.4 语义数据映射

| 页面类型 | 输入字段 | 目标槽位 |
|---|---|---|
| `cover` | `data.title` | `textType: title` |
| `cover` | `data.text` | `textType: content` |
| `contents` | `data.items[]` | `textType: item` |
| `contents` | 项目顺序 | `textType: itemNumber` |
| `transition` | `data.title` | `textType: title` |
| `transition` | `data.text` | `textType: content` |
| `transition` | 章节顺序 | `textType: partNumber` |
| `content` | `data.title` | `textType: title` |
| `content` | `items[].title` | `textType: itemTitle` |
| `content` | `items[].text` | `textType: item` |
| `content` | `images[]` | `imageType: content` |
| `end` | 可选标题和正文 | `title`、`content` |

### 6.5 特殊版式边界

- V1 不增加专用指标页和流程页。
- 后续指标页使用现有 `layoutKind: "metrics"`。
- 普通内容不能因页序轮换误选指标页。
- 流程页只有在现有 `title/items` 数据可无歧义表达时才增加。
- 不为单个模板新增无法复用的私有数据协议。

### 7.3 `template_9.json` 硬约束

- `width` 为 1000，`height` 为 562.5。
- 顶层包含 `slides`、`theme` 和必要的 `metadata`。
- `metadata.mvpSlideIds` 精确包含第 4.1 节的 12 个 MVP 页面。
- 页面 ID 和元素 ID 全部唯一。
- 图片使用 `/api/data/`，不内嵌 Base64 大图。
- 所有资源真实存在，并至少被一个页面引用。
- JSON 建议小于 1MB。
- 图片明确标注为 `content` 或 `decoration`。
- 不包含示例文案、失效 URL、临时目录和本机绝对路径。

### 7.4 必须复用的现有能力

- 模板 ID 符合 `template_<正整数>`，因此 `template_9` 合法。
- 渲染器按目录项和内容项槽位数量选择版式。
- 超量内容按模板最大容量分页。
- 超长正文按可读容量拆分，保持原字符顺序。
- 最小可读字号为 12px。
- `content/decoration` 控制图片替换边界。
- `/api/data/` 模板资源会进行存在性验证。

不得为了 `template_9` 破坏 `template_1`～`template_8` 的生成结果。

## 10. 风险、后续需求与相关资料

### 10.1 主要风险

| 风险 | 影响 | 处理方式 |
|---|---|---|
| 原稿为 3:1 超宽比例 | 直接导入会缩小、裁切或留白 | 所有生产页按 16:9 重构 |
| 原稿没有语义占位符 | Agent 内容无法稳定填充 | 在 PPTist 中重新标注槽位 |
| 特殊字体缺失 | 换机后排版变化 | 使用项目可部署字体并检查导出 |
| 霓虹装饰过多 | 正文可读性下降 | 中央低干扰，装饰限制在边缘 |
| 卡片过密 | 长文溢出和字号过小 | 只承载 1～4 项，超量内容分页 |
| 装饰被 Agent 替换 | 模板视觉损坏 | 严格使用 `content/decoration` 协议 |
| 原 Excel 图表不稳定 | 数据替换和导出风险 | V1 不复用，后续按现有指标协议重建 |
| 素材来源不明 | 商用发布风险 | 只使用原创或授权明确素材 |
| 图片文件过大 | 加载和导出变慢 | JPG 压缩背景，PNG 控制目标大小 |
| 移动端入口不可触达 | 用户不能生成或导出 | 四种视口验收，按钮必须有反馈 |

### 10.2 后续需求，不阻断 V1

- 指标页：使用现有 `layoutKind: "metrics"`。
- 流程页：确认现有 `title/items` 数据足够后再增加。
- 数据分析、芯片信息流、云端设备等扩展插画。
- 统一图标集：只有页面实际需要时再制作。
- 更多封面和章节变体：真实使用数据证明需要后再扩展。
