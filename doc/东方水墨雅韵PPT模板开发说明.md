# 东方水墨雅韵 PPT 模板开发说明

> 状态：`DONE`
> 模板 ID：`template_12`
> 模板名称：`东方水墨雅韵`
> 参考文件：`中国风格(01).pptx`
> 本文定义开发目标和验收标准；G0～G8 自动验收已通过，用户已确认完成并闭合。

## 1. 目标与开发边界

### 1.1 开发目标

基于参考 PPT 的水墨山水、折扇、印章、蓝灰配色和留白构图，为 TrainPPTAgent 新增一套可生成、可编辑、可配图、可导出并可重新导入的中国风生产模板。

生产版固定为 18 页，先完成 12 页 MVP，再增加第二封面、第二章节、单结论、单图文、三指标和替代四项内容页。

完成后应支持：

- 封面、目录、章节、内容和结束五种页面；
- 2、3、4、5、6、10 项目录精确选版；
- 1～4 项普通内容选版及超量、超长内容分页；
- 数字指标专用页面；
- Agent 内容配图与固定装饰隔离；
- 在线编辑、PPTX 导出和重新导入；
- 桌面、笔记本、平板和手机端操作。

### 1.2 开发范围

- 审计参考 PPT 的页面、字体、图片和版权风险。
- 建立参考页面与 18 页生产模板的映射。
- 固化画布、颜色、字体、字号和安全区。
- 生产并实际引用 8 项原创背景和透明装饰素材。
- 构建 12 页 MVP，完成 PPTist 语义标注并验证生成能力。
- 扩展为 18 页生产模板，注册模板和封面资源。
- 增加结构、容量、分页、图片和资源专项测试。
- 完成真实生成、多设备、PPTX 导出和重导入 QA。

### 1.3 开发边界

- 参考 PPT 只提供视觉和布局方向，不直接作为生产模板发布。
- 未确认授权的图片、字体、音频、Logo 和水印不得进入生产目录。
- 动态标题、正文、目录、编号和指标必须保持可编辑。
- 不为本模板新增私有 Agent 数据协议，不重写编辑器或渲染器架构。
- 只有测试证明现有能力不足时，才最小化修改渲染器或前端。
- 默认不提交、推送、创建 PR、合并或部署。

### 3.3 选版和分页规则

- 目录严格按 2、3、4、5、6、10 项选择精确容量页面。
- 无图片普通内容优先选择容量匹配的纯文字页面。
- 一项普通内容选择单结论页；一项内容加一张图片选择单图文页。
- 二、三、四项普通内容分别选择对应容量页面。
- `metric`、`number`、`stat` 等数字语义进入三指标页。
- 超过四项的普通内容按最大内容容量分页，项目顺序保持不变。
- 超长正文分页后不得丢字；带图长正文只在第一页保留一次内容图。
- 两种封面和两种章节页必须能通过稳定种子分别选中。

## 5. PPTist 语义与模板数据契约

### 5.1 页面和文字角色

生产模板只使用 `cover`、`contents`、`transition`、`content`、`end` 五种页面类型。

| 文字角色 | 用途 |
|---|---|
| `title` | 封面、页面或章节标题 |
| `content` | 封面副标题、章节说明、结束页正文 |
| `item` | 目录项或内容项正文 |
| `itemTitle` | 内容项标题 |
| `itemNumber` | 目录或内容项目编号 |
| `partNumber` | 章节编号 |

文本槽可以是文本元素，也可以是带文字的形状。同一内容项的 `itemTitle`、`item` 和 `itemNumber` 必须使用一致的 `groupId`。

### 5.2 图片角色

- Agent 可替换图片使用 `imageType: "content"`。
- 水墨背景、山形、笔触、折扇、圆形框景和印章使用 `imageType: "decoration"` 或项目支持的背景类型。
- 装饰图锁定，不参与 Agent 图片替换。
- 内容图不设置内容项 `groupId`，避免参与文本组复制。
- 单图文页按需设置 `strictImageCount`。
- 内容图设置 `requireSourceDimensions: true`。
- 图片使用中心裁切协议，不能拉伸填满容器。

### 5.3 指标页面

- 三指标页使用 `layoutKind: "metrics"`。
- 指标继续使用现有 `title/items` 数据结构，不新增模板私有字段。
- 普通三项内容不得误选指标页。

### 5.4 `template_12.json` 硬约束

- 模板 ID 为 `template_12`，名称为“东方水墨雅韵”。
- 画布为 `1000 × 562.5`，页面总数为 18。
- 页面类型数量为 2 个封面、6 个目录、2 个章节、7 个内容、1 个结束页。
- `metadata.mvpSlideIds` 精确包含 12 个页面 ID。
- 页面 ID 和元素 ID 全局唯一。
- 图片统一使用 `/api/data/` 地址，JSON 不内嵌 Base64 大图。
- JSON 不包含本机绝对路径、临时目录和参考稿示例文字。
- 每页 `remark` 保存 `[Sources]` 来源块。
- `metadata.sourceReference` 记录 `中国风格(01).pptx`。
- 元数据明确记录内容图片和装饰图片标记。

## 7. 测试与验收标准

### 7.1 结构和资源

- 模板 ID、名称、画布和元数据正确。
- 页面总数为 18，类型数量为 2/6/2/7/1。
- 12 页 MVP ID 存在且唯一。
- 页面和元素 ID 全局唯一。
- JSON 无本机路径、临时目录、Base64 大图和参考示例文字。
- 8 项素材全部被引用，发布目录没有未引用的 `template_12_asset_*` 文件。
- 背景和透明素材满足尺寸、模式、体积和 Alpha 要求。
- 模板封面为 960×540 RGB JPEG，体积小于 350KB。

### 7.2 内容、分页和图片

- 目录按 2、3、4、5、6、10 项精确选版。
- 1～4 项普通内容选择正确容量页面。
- 数字指标稳定进入指标页，普通内容不误选指标页。
- 8 项内容分页后项目顺序不变。
- 长正文分页后字符完整；带图长正文只保留一次内容图。
- Agent 图片只填充 `imageType: "content"`，装饰保持项目资源路径。
- 图片多于正文项或缺少源图尺寸时明确失败。
- 横图、竖图和方图均保持裁切框比例，不发生拉伸。
- 无图片输入时不出现破图和异常空框。

建议内容边界：

| 内容 | 边界 |
|---|---:|
| 页面标题 | 最长 40 个中英文混排字符 |
| 内容项标题 | 最长 30 个字符 |
| 目录项 | 每项最长 14 个中英文混排字符 |
| 单项正文 | 1 项 90 字、2 项各 90 字、3 项各 60 字、4 项各 45 字 |

超出边界时允许分页，不允许丢字或缩小到最低字号以下。

### 7.3 视觉、设备和交互

- 18 页逐页检查，无文字溢出、异常换行、重叠、破图和装饰遮挡。
- 动态文字可编辑，图片裁切、圆形框景、折扇和印章位置稳定。
- 导出前后字体、换行、位置和裁切保持可接受的一致性。
- 在 1920×1080、1366×768、768×1024、390×844 四种视口检查主流程。
- 页面无横向溢出，预览画布保持 16:9，模板卡片有清晰选中状态。
- 加载、成功、失败、重试、返回、替换图片、下载和导出都有可见反馈。
- 暂时只能提供假性交互的按钮也必须明确反馈，不能点击无反应。

### 7.4 PPTX 与回归

- 真实生成作品可以导出 PPTX。
- 导出 PPTX 可以重新导入项目并继续编辑文字和内容图片。
- `template_1`～`template_11` 关键能力无回归。
- 若修改前端，前端类型检查、单元测试和生产构建通过。

第 7 章全部验收项通过后，模板进入 `READY_FOR_CONFIRMATION`。只有用户人工确认后，才能完成 Goal 闭合。只完成文档、素材、MVP、注册或单个测试，不算开发完成。

| AI 素材出现伪汉字 | 提示词禁止文字并逐张人工检查，问题素材不发布 |
| 透明素材带白底或白边 | 检查 Alpha，并在深浅背景上分别预览 |
| 装饰被 Agent 配图覆盖 | 使用 `imageType`、资源路径和专项测试三重保护 |
| 纵向文字导出漂移 | 只在少量章节编号中受控使用，动态正文保持横排 |
| 长文本破坏留白 | 设置容量并分页，不降低到最低字号以下 |
| 移动端操作受阻 | 仅在真实 QA 有证据时进行响应式最小修复 |
