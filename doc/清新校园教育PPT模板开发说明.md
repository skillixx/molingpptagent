## 1. 文档信息与开发原则

| 项目 | 内容 |
|---|---|

| 文档日期 | 2026-08-25 |

本文指导开发者把参考 PPT 的白底、绿色树叶、草坡、校园氛围和手绘教育视觉，重构为 TrainPPTAgent 可生成、可编辑、可替换内容图片、可导出和可回归测试的生产模板。

开发时必须遵守以下原则：

1. 不直接把参考 PPTX 当作生产模板，必须在 PPTist 中重建并标注语义槽。
2. 先完成 12 页 MVP，通过生成、编辑、图片保护和 PPTX 往返后，再扩展到 18 页。
3. 标题、正文、编号和内容图片必须是独立、可编辑的 PPTist 元素。
4. 内容图片使用 `imageType: "content"`，背景和固定装饰使用 `imageType: "decoration"`。
5. 复用现有 Agent 数据协议和模板渲染器，不为单个模板增加私有字段。
6. 默认不修改渲染器和前端；只有测试证明现有能力不足时，才允许兼容性修改。

> 本文只定义开发范围、实施任务和验收标准。当前没有创建模板 JSON、封面、装饰图或测试文件，也没有修改代码、运行测试、提交或部署。

## 2. 目标、范围和非目标

### 2.1 完成后的用户能力

- 模板选择页显示“清新校园教育”和真实模板封面。
- 能稳定生成封面、目录、章节、内容和结束页。
- 目录支持 2、3、4、5、6、10 项精确容量。
- 内容页支持 1、2、3、4 项，超量和超长内容可以无损分页。
- 指标内容可以选择 `layoutKind: "metrics"` 的专用页面。
- Agent 配图只进入内容图片槽，不覆盖树叶、草坡和儿童插画等固定装饰。
- 横图、竖图和方图可以居中裁切，不拉伸变形。
- 生成结果可以编辑文字、替换内容图片、导出 PPTX，并重新导入项目。
- 桌面、笔记本、平板和手机端没有横向溢出，主要按钮可触达且有反馈。

## 4. MVP 和生产版页面清单

### 4.1 MVP：12 页

MVP 用于验证“语义数据 → 模板选版 → 内容填充 → 编辑 → 导出”的完整链路。

| 页面代码 | 类型 | 容量和用途 |
|---|---|---|
| `COV-01` | `cover` | 主封面，标题支持两行，副标题可为空 |
| `DIR-02` | `contents` | 2 项目录 |
| `DIR-03` | `contents` | 3 项目录 |
| `DIR-04` | `contents` | 4 项目录 |
| `DIR-05` | `contents` | 5 项目录 |
| `DIR-06` | `contents` | 6 项目录 |
| `DIR-10` | `contents` | 10 项紧凑目录 |
| `SEC-01` | `transition` | 章节编号、标题和可选说明 |
| `CNT-02` | `content` | 2 项纯文字 |
| `CNT-03` | `content` | 3 项纯文字 |
| `CNT-04` | `content` | 4 项纯文字 |
| `END-01` | `end` | 结束标题和可选说明 |

MVP 未通过真实生成、长文本、图片保护和 PPTX 往返测试前，不进入生产版扩展。

### 4.2 生产版 V1：18 页

MVP 通过后增加以下 6 页：

| 页面代码 | 类型 | 容量和用途 |
|---|---|---|
| `COV-02` | `cover` | 左文右侧原创儿童插画封面 |
| `SEC-02` | `transition` | 左侧标题、右侧校园内容图片章节页 |
| `CNT-01` | `content` | 单结论、核心观点或大段引言 |
| `CNT-IMG-01` | `content` | 单图文，1 个内容图片槽 |
| `CNT-MET-03` | `content` | 三项数据指标，`layoutKind: "metrics"` |
| `CNT-04B` | `content` | 四步流程或四阶段内容的第二种四项构图 |

生产版共 18 页：2 个封面、6 个目录、2 个章节、7 个内容页和 1 个结束页。

### 4.3 选版规则

- 目录按 `items` 数量选择容量最接近且足够的页面。
- 普通内容按 1、2、3、4 项选择对应容量页面。
- `CNT-04` 与 `CNT-04B` 都使用普通内容语义，由现有轮换逻辑选择。
- 数字、百分比、金额、年份等指标项可以触发 `layoutKind: "metrics"`。
- 有 Agent 配图时优先选择图文页；无图时优先选择纯文字页。
- 超过四项的内容由渲染器分页，不能挤入一个页面。

### 5.3 素材生产和验收

- 所有素材必须原创或具有明确商用授权。
- 不得包含文字、数字、Logo、水印、校徽、按钮、假截图和假数据。
- 不得生成可识别真人或复制现有版权角色。
- 透明 PNG 必须具有真实 Alpha 通道，不能带白底、棋盘格或矩形边缘。
- 每项素材保存最终提示词、实际模型、原始输出、发布路径和人工检查结果。
- 发布素材必须满足表格中的尺寸、颜色模式和体积限制，并被模板至少引用一次。

背景和插画提示词保存到执行阶段的 `doc/assets/template_10_qa/image-prompts.md`，不在主开发说明中维护完整提示词。

### 5.4 哪些元素不用生成图片

矩形、圆形、卡片、分隔线、章节数字、流程箭头、步骤节点、数据环、图片蒙版和普通阴影使用 PPTist 原生形状，保持可编辑和清晰导出。

## 6. 模板专属语义约束

项目通用页面类型和数据结构以 [`PPT_Structure.md`](./PPT_Structure.md) 为参考，生产行为以当前渲染器和测试为准。本节只记录 `template_10` 的专属约束。

### 6.1 文字和分组

- 页面类型只使用 `cover`、`contents`、`transition`、`content`、`end`。
- 标题使用 `textType: "title"`，正文使用 `content` 或 `item`。
- 内容项标题使用 `itemTitle`，目录或内容编号使用 `itemNumber`。
- 章节编号使用 `partNumber`。
- 同一内容项的编号、标题、正文和伴随形状使用相同 `groupId`。
- 内容项不足时删除整个未使用分组，不能留下空编号或孤立装饰。

### 6.2 图片

- 树叶、草坡、儿童群像、笔刷和角落用品使用 `imageType: "decoration"` 并锁定。
- 校园照片和其他 Agent 配图槽使用 `imageType: "content"`，保持可选中和可替换。
- 单图文页使用 `strictImageCount: true`，确保正文项与图片数量一致。
- 需要裁切的内容图片槽使用 `requireSourceDimensions: true`。
- 没有图片输入时优先选择纯文字页，不能留下空图片框或破图。

### 6.3 指标和流程

- `CNT-MET-03` 使用 `layoutKind: "metrics"`。
- `kind` 为 `metric`、`number` 或 `stat` 的内容项可以触发指标页。
- 普通四项内容不能因为页面轮换误选指标页。
- 四步流程页继续使用普通 `title/items`，不新增 `process` 私有字段。

### 9.2 主要风险

| 风险 | 影响 | 处理方式 |
|---|---|---|
| 原稿有 10 个母版和 48 个版式 | 直接导入难维护 | 归并为 18 个语义页面 |
| 原稿没有语义占位符 | Agent 无法稳定填充 | 在 PPTist 中重新标注 |
| 非标准字体较多 | 换机或导出后排版变化 | 统一微软雅黑和 Arial |
| 原稿素材授权不明确 | 商用发布风险 | 只使用原创或授权明确素材 |
| 装饰或卡片过多 | 正文可读性下降 | 装饰限制在边缘，超量内容分页 |
| 装饰被 Agent 替换 | 模板主视觉损坏 | 严格标记 `content/decoration` |
| 图表和 SmartArt 不稳定 | 数据替换与导出风险 | 使用指标协议和原生形状重建 |
| 为单模板修改渲染器 | 可能破坏旧模板 | 默认不改，测试证明必要时才兼容扩展 |

### 9.3 完成定义

模板只有同时满足以下条件，才能从 `PLANNED` 进入 `DONE`：

1. 12 页 MVP 和 18 页生产版完成。
2. 模板 JSON、封面和全部实际引用素材进入生产目录。
3. 专项测试、通用渲染器测试和旧模板回归通过。
4. 真实生成、文字编辑、图片替换、失败重试和多设备检查通过。
5. PPTX 导出和重新导入通过。
6. 素材来源、提示词、截图、测试和已知限制记录完整。
7. 全部自动验收完成并形成可复查证据后进入 `READY_FOR_CONFIRMATION`；用户明确确认后标记 `DONE` 并闭合。
