## 2. 模板定位与参考稿结论

### 2.1 模板定位

“桃夭墨韵商务汇报”是一套粉彩桃花与水墨宣纸风格的通用演示模板。

适用场景包括文化宣传、国风品牌、旅游文创、节庆活动、女性消费和轻商务汇报。

核心视觉由暖象牙宣纸、粉彩桃花、淡墨山景、卷轴、花瓣、水墨题框和酒红文字组成。正文区保留大面积低干扰留白，避免做成满版插画或仿古海报。

标题、正文、目录、编号、指标、行动项和业务图片必须可编辑、可替换、可生成。桃花、水墨边框、卷轴和花瓣只承担固定装饰角色。

### 2.2 参考稿审计摘要

| 检查项 | 结论 | 开发影响 |
|---|---|---|
| 画布 | 960×540，16:9 | 映射为项目画布 1000×562.5 |
| 页面 | 26 页 | 可覆盖五类核心页面和多种内容结构 |
| 母版与版式 | 1 个母版、12 个版式 | 只作为结构参考，不直接发布 |
| 实际内容占位符 | 幻灯片级占位符不足 | 必须重建项目语义槽 |
| 项目解析器 | 26 页均可读取，无空页 | 可以作为重构输入 |
| 媒体 | 48 个媒体文件，含 1 个 MP3 | 默认排除源媒体、音频和动画 |
| 字体 | 多种特殊字体未嵌入 | 替换为项目稳定字体 |
| 图表与表格 | 无原生图表和表格 | 指标与关系图使用可编辑形状 |

结论：参考稿适合重构为项目原生模板，但不能直接复制为生产 JSON，也不能直接发布源媒体。

### 2.3 字体策略

- 中文标题、正文和目录默认使用微软雅黑。
- 英文和数字使用 Arial。
- 宋体只可用于短章节数字或短标题，并且必须先通过编辑器、导出和重导入验证。
- 不使用华文隶书、华文新魏、叶根友毛笔行书 2.0 版和 Adobe 黑体 Std R。
- 不把书法标题烘焙到背景图片中，所有动态文字必须保持可编辑。

### 2.4 视觉查重（非阻塞）

`template_22` 的设计重点是桃花边景、卷轴、干笔题框、粉色山影和轻盈留白。与已上线模板的相似或差异只记录为设计备注，不读取或继承旧模板的阶段、库存、素材数量和验收流程，也不影响当前任务通过。

### 3.2 三页技术探针

完整模板开发前，先完成以下三页探针：

| 页面 ID | 目标 | 必须验证 |
|---|---|---|
| `cover-scroll-blossom` | 封面 | JSON 导入、标题编辑、装饰锁定和 PPTX 往返 |
| `content-image-1` | 普通图文 | 横图、竖图、方图替换及内容图与装饰隔离 |
| `probe-image-circle-1` | 特殊图片 | 单张圆图换图、圆形裁切、装饰保护及 PPTX 往返 |

`probe-image-circle-1` 只包含一张可替换圆形内容图和对应文字，是探针专用页面，不进入 18 页生产库存。使用横图、竖图和方图分别验证同一图片槽即可；不实现三图画廊、三图选版或多图调度。

G2 使用固定数据、既有授权明确的测试图片、Fake/Mock 和隔离环境，不调用文本模型或图片生成工具。探针失败时自动增加失败测试、修复和重验；通过前不扩展完整模板，但不为普通失败请求人工确认。G3 的规划内 GPT2 图片生成按第 5.1 节单独执行。

### 3.4 18 页核心生产版

MVP 通过后增加以下 6 页：

| 页面 ID | 类型 | 用途 |
|---|---|---|
| `cover-blossom-minimal` | `cover` | 留白更多的第二封面 |
| `transition-ink-circle` | `transition` | 淡墨圆框第二章节页 |
| `content-statement-1` | `content` | 单结论、摘要或引语 |
| `content-image-1` | `content` | 一张可替换内容图加一项正文 |
| `content-metrics-4` | `content` | 四项可编辑业务指标 |
| `end-action` | `end` | 1～3 项行动结束页 |

生产库存固定为 2 张封面、6 张目录、2 张章节、6 张内容和 2 张结束页，共 18 页。

流程、时间轴、三项比较、Venn 图、三图圆框和路线图不进入第一版。需要这些版式时，应创建独立扩展任务。

### 3.5 选版与分页

- 目录按 2、3、4、5、6、10 项选择精确容量页面。
- 单项无图正文选择 `content-statement-1`。
- 2～4 项无图正文选择 `content-text-2/3/4`。
- 一项正文加一张业务图片选择 `content-image-1`。
- 四项指标或 `layoutKind: metrics` 选择 `content-metrics-4`。
- 指标页必须恰好包含 4 项，每项保留标题、数值和说明。
- 超过 4 项的正文和超过 10 项的目录执行无损分页。
- 带图长正文只在第一页保留内容图，续页不得留下空图片框。
- 结束页支持 0～3 个行动项，超过 3 项显式失败。
- 分页增长策略采用 `factor: 1.75`、`slack: 5`。
- 页面异常膨胀抛出 `TEMPLATE_PAGINATION_EXPLOSION`。
- 禁止通过截断标题或正文制造“适配成功”。

## 4. 视觉系统

### 4.1 画布与安全区

| 项目 | 规范 |
|---|---|
| 逻辑画布 | 1000×562.5，16:9 |
| 水平安全区 | 56～944px |
| 垂直安全区 | 40～520px |
| 页面标题区 | 70～96px |
| 正文与装饰最小距离 | 20px |
| 内容图与装饰最小距离 | 18px |
| 低干扰内容区 | 不低于页面的 72% |
| 侧边装饰最大侵入宽度 | 页面宽度的 28% |

本节 72% 留白比例与正文背景 75% 留白比例用于设计引导，不作逐像素测量或单独的失败依据。验收检查实际文字是否可读、完整显示、是否被装饰遮挡，以及编辑操作是否可达。

### 5.1 素材生产规则

- 模板所需的原创背景和透明装饰可以优先使用 GPT2 图片模板生成。
- “GPT2 图片模板”是本规划采用的图片生成方式名称；工具未暴露底层模型名称时记录“工具未暴露”，不得猜测或伪造模型信息。
- 开始开发的授权生效后，G3 当前规划素材及每项最多 3 轮生成属于已列明的图片生成例外，无需逐图再授权。G2、自动化测试和 G8 处理链使用固定输入，不在这些检查中调用真实文本模型或图片生成工具。
- 背景使用 JPEG；透明装饰使用 RGBA PNG。
- 每项素材单独生成，不制作九宫格或待切割拼图。
- 每项素材最多自动生成或重试 3 轮，达到规格后停止。
- 素材不得包含文字、数字、Logo、水印、二维码、产品界面和业务数据。
- PNG 必须具有真实 Alpha 通道，不得用白底或灰底伪装透明。
- 背景必须为动态文字预留负空间，装饰不得穿越标题和正文安全区。
- G3 检查候选素材自身质量并记录目标页面；G5 检查 MVP 引用的素材可读取；G7 只保留并发布被 18 页生产 JSON 实际引用的素材。
- 不因“相似度不足”或“差异度不足”追加生成；用途、清晰度、尺寸、格式、透明通道和文字可读性符合要求后即停止该素材的迭代。
- 禁止复制、改名、抠图或轻微调色源 PPTX 媒体后作为新素材。

## 6. PPTist 语义与内容契约

### 6.1 页面和文字角色

生产页面只使用 `cover`、`contents`、`transition`、`content` 和 `end`。

| 文字角色 | 用途 |
|---|---|
| `title` | 封面、页面、章节或结束标题 |
| `content` | 副标题、章节说明、单结论和结束说明 |
| `item` | 目录项、正文、指标说明和行动项 |
| `itemTitle` | 内容项或指标标题 |
| `itemNumber` | 目录编号、内容编号或指标数值 |
| `partNumber` | 章节编号 |

普通文本使用 `textType`。带文字形状使用 `element.text.type`。

同一文档内页面 ID、元素 ID 全局唯一；不同内容组使用不同 `groupId`，同组的编号、标题、正文和图片共享同一个 `groupId`。这些 ID 必须稳定且可重复构建，不得把组内共享 ID 判为重复错误。

所有动态文字槽必须声明 `minimumFontSize`。生产 JSON 不保留“请输入内容”等源稿占位文字。

### 6.2 图片角色

| 图片角色 | 行为 |
|---|---|
| `imageType: "content"` | Agent 可填图，用户可替换，必须声明原始尺寸和裁切 |
| `imageType: "decoration"` | 固定装饰，必须锁定，不得被业务图片替换 |

内容图片与对应标题、正文共享 `groupId`。图片槽必须覆盖横图、竖图和方图，并使用稳定居中裁切。

圆形图片使用项目 `clip` 契约。导出和重导入后，图片必须保持圆形、可选中和可替换。

### 6.3 内容完整性

- 原始标题和正文信息不得丢失。
- 原始项目顺序不得变化。
- 展示标题需要缩短时，完整原标题写入 `sourceTitle` 并合并到对应正文。
- 标题适配与正文分页分别处理，长标题不得把四项页退化为四张单项页。
- 指标标题、数值和说明保持独立，项目编号不得覆盖指标数值。
- 容量不足时只能换版、分页或显式报错，禁止静默截断。

### 6.4 资源限制

- 装饰资源使用 `/api/data/template_22_asset_*`。
- 禁止 Base64 大图、`file://`、本机绝对路径和临时目录路径。
- `template_22.json` 建议小于 1MB。
- `template_22.jpg` 固定为 960×540、RGB JPEG，建议小于 150KB。
- 第一版不包含原生 `chart`、音频、视频、动画和自动播放。
- G7 正式发布集合不得包含未被生产 JSON 引用的 `template_22_asset_*` 文件。G3～G6 的待用素材及探针素材保存在 QA 目录；G5 不要求后续页面素材已被 MVP 使用。
- 默认不修改公共模板渲染器；只有失败测试证明协议不足时才提出最小修改。

## 8. 核心验收与风险

### 8.1 核心验收

- 12 页 MVP 和 18 页生产库存准确。
- 构建器对相同输入产生相同结果。
- 页面 ID、元素 ID 全局唯一；不同组的 `groupId` 不冲突，同组元素共享 `groupId`。
- 目录和正文精确选版，超量内容无损分页。
- `sourceTitle`、正文和项目顺序完整保留。
- 四项正文不因标题适配退化为大量单项页。
- 内容图片与装饰图片严格隔离。
- 横图、竖图和方图裁切正确。
- JSON 保存重载和 PPTX 往返后核心结构稳定。
- 1920×1080、1366×768、768×1024 和 390×844 四种视口无操作遮挡。
- 冻结候选版本完成一次正式测试与视觉证据。

上述检查保留可编辑性、内容完整性、资源可用性、裁切和导出稳定性的通过要求。主观视觉意见记录为 `NOTE`，不独立触发 `NEEDS_FIX`、`BLOCKED` 或重复完整验收；出现可复现的丢字、遮挡、破图或导出错误时才修复相应问题。

### 8.2 主要风险

| 风险 | 处理方式 |
|---|---|
| 源媒体和特殊字体授权不明 | 排除源媒体，使用原创素材和稳定字体 |
| 桃花装饰影响阅读 | 依据实际文字遮挡与可读性调整边缘装饰，留白比例作为参考 |
| 主观相似度或差异度引发反复返工 | 保留设计方向并记录非阻塞备注，不设置评分门槛，不为此重生成合格素材 |
| 竖排标题容量不足 | 仅用于封面和章节，最多 8 字 |
| 圆形图片回环退化 | 使用 `clip` 契约并在 G2 验证三种宽高比 |
| 长标题造成分页膨胀 | 使用 `sourceTitle`，分离标题适配与正文分页 |
| 素材数量失控 | 以当前候选清单为起点，只发布实际引用素材 |
