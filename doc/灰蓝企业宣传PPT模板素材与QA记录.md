### 2.2 字体审计

参考稿包含微软雅黑、宋体、华文黑体、方正兰亭黑简体、Arial、Calibri、Impact等多种字体，并包含大量Office历史兼容字体。

生产处理：

- 中文动态文字统一使用微软雅黑。
- 英文和数字使用Arial或微软雅黑。
- 不依赖方正兰亭黑简体、华文黑体和历史兼容字体。
- 导出和重新导入后重新检查换行和文本框高度。

### 2.3 页面映射结论

| 生产用途 | 参考页 | 处理方式 |
|---|---|---|
| 主封面 | 1 | 保留标题区与图片区关系，重建背景和文字 |
| 目录族 | 2 | 派生2、3、4、5、6、10项目录 |
| 深色章节 | 3或10 | 使用折面边缘和大章节编号 |
| 浅色章节 | 17或23 | 使用建筑线稿和留白构图 |
| 2项正文 | 24 | 重建双项语义组 |
| 3项正文 | 21或27 | 重建三项语义组 |
| 4项正文 | 6、12或28 | 重建四项语义组 |

| 单图文 | 11或25 | 拆分独立内容图槽 |
| 双图文 | 22 | 拆分两个内容图槽，不复用原图 |
| 联系方式 | 29 | 地址、电话和邮箱全部保持可编辑 |
