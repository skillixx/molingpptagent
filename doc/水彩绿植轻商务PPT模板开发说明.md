## 2. 产品定位与差异化

### 2.1 模板定位

“水彩绿植轻商务”面向工作汇报、企业培训、健康生活、自然主题、品牌介绍、文旅公益和阶段复盘。模板提供自然、清新、低压力的视觉氛围，但不限定为教育课件。

### 2.2 与 `template_10` 的差异

| 维度 | `template_10 清新校园教育` | `template_19 水彩绿植轻商务` |
|---|---|---|
| 核心场景 | 校园、课堂和教育培训 | 轻商务、生活方式和自然主题 |
| 主要视觉 | 树冠、草坡、儿童和校园用品 | 桉叶、蕨叶、水彩纸纹和植物框景 |
| 页面气质 | 活泼、亲和、面向学习 | 克制、安静、适合通用汇报 |
| 装饰密度 | 中等，包含具象校园插画 | 低到中等，植物集中在边缘 |
| 内容布局 | 教育卡片和学习步骤 | 平面分栏、留白、指标和图文 |

本模板不得使用儿童群像、书本、铅笔、校徽、校园草坡或密集教育图标，否则会与 `template_10` 失去区分。

### 2.3 完成后的用户能力

- 生成封面、目录、章节、内容和结束五种页面。
- 编辑标题、正文、编号和指标，不把动态内容做成图片。
- 替换业务图片，同时保留水彩植物和纸纹装饰。
- 导出并重新导入 PPTX，保留文字、图片、装饰和裁切。

## 6. 模板语义、选版与分页

页面类型和通用文字角色沿用 [`PPT_Structure.md`](./PPT_Structure.md)。本模板只补充图片隔离、内容分组、容量、标题和分页约束。

### 6.1 模板专属字段

| 字段 | 用途 |
|---|---|
| `groupId` | 绑定同一内容项的编号、标题、正文和业务图片 |
| `imageType: "decoration"` | 标记固定背景和植物装饰，默认锁定 |
| `imageType: "content"` | 标记可选中、可替换的业务图片 |
| `strictImageCount` | 限制业务图片数量与内容项匹配 |
| `requireSourceDimensions` | 要求业务图片提供原始宽高，以便正确裁切 |
| `minimumFontSize` | 定义文本槽允许的最小字号 |
| `titleFitLimits` | 定义中英文混排标题容量 |
| `sourceTitle` | 无损保存原始完整内容项标题 |

内容项不足时删除整个未使用分组，不留下空编号、空图片框或孤立装饰。

### 6.2 图片规则

- Agent 图片只填充 `imageType: "content"` 的业务图片槽。
- 横图、竖图和方图使用稳定居中裁切，不拉伸。
- 无图输入选择纯文字页，不显示空图片框。
- 图文长正文只在第一页保留业务图片。
- 图片数量超过内容项数量时显式失败，不静默丢弃图片。

### 6.3 选版和分页

- 目录按 2、3、4、5、6、10 项选择精确容量页面。
- 无图内容按 1、2、3、4 项选择对应页面。
- 单项正文加一张图片选择 `content-image-1`。
- 四项数字、百分比、金额或统计语义选择 `content-metrics-4`。
- 超过 4 项的普通内容和超过 10 项的目录无损分页。
- 长正文拆分后保持原始顺序和完整字符，不重复、不截断。
- 结束页按 0 项和 1～3 项行动选择；超过 3 项显式失败。

### 6.4 标题容量与页面膨胀

真实内容项标题通常为 11～16 个中文字符。模板不能仅因标题过长，把四项内容静默退化成四张单项页。

安全短标题写入 `itemTitle`，原始标题保存到 `sourceTitle`，必要时无损合并进正文。2～4 项页面的标题槽必须在最小字号下全部容纳安全短标题。

分页密度只由真实槽位和正文容量决定。页面数量超过计划页数的 1.5 倍加 5 页时，应显式失败并记录规模统计，不记录用户完整正文。

G9 在冻结候选版本上执行最终自动复核。自动检测没有问题后只能进入 `READY_FOR_CONFIRMATION` 并停止闭合；收到用户明确人工确认后，才允许完成闭合并进入 `DONE`。用户明确接受已记录问题时，才可进入 `DONE_WITH_CONCERNS`。

### 8.2 关键风险

| 风险 | 影响 | 处理方式 |
|---|---|---|
| 与 `template_10` 重叠 | 模板列表缺少增量价值 | 保持轻商务定位，不使用儿童、校园用品和草坡 |
| 参考媒体授权不明 | 无法合法发布 | 默认排除，使用原创或授权明确素材 |
| 无语义占位符 | Agent 无法稳定填充 | 使用项目 JSON 语义槽重建 |
| 长标题造成单项页退化 | 页面数量和节奏失控 | 使用安全短标题、`sourceTitle` 和页面膨胀保护 |
| Worker 重试重复页面 | 页数、成本和预览异常 | 作为公共问题处理；复现时阻止最终验收 |
| 装饰侵入正文区 | 文字遮挡或预览不清晰 | 执行安全区和侵入比例约束 |
| 图表或嵌入对象不稳定 | 导出后数据丢失 | 使用基础形状和文字重建 |
| 为单模板修改公共代码 | 可能破坏旧模板 | 先用探针和测试证明必要性 |

技术探针失败、文字容量不足、图片隔离失败、PPTX 往返失败或正式 QA 退化时，执行者先自动定位、修复和重验。只有安全替代方案耗尽、同一阻断连续出现至少三个 Goal 回合且没有其他范围内工作可继续时，才标记 `blocked`。

候选版本冻结后集中生成一次正式验收证据。没有文件变化或失败证据时，不重复已经通过的阶段；修改图片槽、裁切或公共渲染器后，按影响范围重新验证。

G9 自动验收通过只表示可以请求用户确认。用户明确确认前，必须保持 `READY_FOR_CONFIRMATION`，不得调用完成工具、执行闭合或把项目状态写成 `DONE`。
