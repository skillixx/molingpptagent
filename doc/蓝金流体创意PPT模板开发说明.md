# 蓝金流体创意 PPT 模板开发说明

> 文档状态：`DONE`
> 计划模板：`template_11` / 蓝金流体创意
> 参考文件：`创意风格 (56).pptx`
> 当前状态：G0～G8 自动验收已完成，用户已于 2026-08-26 确认闭合。提交、推送、PR、合并和部署未执行。

## 1. 开发结论

参考 PPT 共 25 页，比例为 16:9，主视觉是深蓝、雾蓝、象牙白和灰绿色液态纹理。原稿包含封面、目录、章节、内容、指标、图文、流程、SWOT 和结束页，适合改造成 TrainPPTAgent 模板。

原稿不能直接放入生产目录。它没有可供生成器使用的语义占位符，还包含动画、页面切换、约 8.1 MB 的音频、非标准字体和多处版权声明。

开发方式固定为：

`授权与原创替代检查 → 页面审计 → 视觉样稿 → 7 项核心素材 → 12 页 MVP → 容量验证 → 18 页生产版 → 接入与测试 → G8自动验收 → 人工确认闭合`

开发者开始前先记住以下规则：

1. 不直接发布原始 PPTX，只参考其构图和视觉关系。
2. 授权不明确的背景、照片、音乐、字体和版权内容不得进入生产模板。
3. 先完成 12 页 MVP，验证生成链路后再扩展到 18 页。
4. 文字、数据、编号和流程必须保持可编辑，不合成为大图。
5. Agent 图片只能替换内容图片，不能覆盖背景和固定装饰。
6. 默认不修改渲染器和前端；只有测试证明存在缺口时才做兼容修改。

## 2. 开发范围与授权边界

### 2.1 要完成的能力

- 模板选择页显示“蓝金流体创意”和真实封面。
- 能生成 `cover`、`contents`、`transition`、`content`、`end` 五种页面。
- 目录精确支持 2、3、4、5、6、10 项。
- 普通内容支持 1、2、3、4 项，超量或超长正文无损分页。
- 指标内容可以进入专用 `metrics` 页面。
- 内容图片可以编辑和替换，背景与装饰保持不变。
- 生成结果可以导出 PPTX，并重新导入项目继续编辑。
- 桌面、笔记本、平板和手机端无横向溢出，操作按钮都有反馈。

### 2.2 不在本次范围

- 不直接复制或发布原始 PPTX。
- 不使用授权不明确的图片、字体、Logo、音乐和水印。
- 不为 `template_11` 增加私有 Agent 字段或重写编辑器。
- 不生成假 Logo、假截图、假数据、假证书和可识别真人。
- 本次已完成素材、模板、代码接入和测试；提交、推送、PR、合并和部署仍不在 Goal 范围。

### 2.3 授权要求

正式制作素材前，必须确认参考 PPT 的商业使用和改编范围。无法确认授权时，只保留抽象构图关系，所有背景、照片和装饰使用原创或授权明确的替代素材。

版权文字不能在未授权时直接删除后商用。原有音乐、动画、切换和山水照片默认从生产模板中移除。

## 4. MVP 与生产版页面

### 4.1 12 页 MVP

MVP 用于验证“语义数据 → 模板选版 → 内容填充 → 编辑 → 导出”的完整链路。

| 页面代码 | 类型 | 用途 |
|---|---|---|
| `COV-01` | `cover` | 主封面，标题支持两行，副标题可为空 |
| `DIR-02` | `contents` | 2 项目录 |
| `DIR-03` | `contents` | 3 项目录 |
| `DIR-04` | `contents` | 4 项目录 |
| `DIR-05` | `contents` | 5 项目录 |
| `DIR-06` | `contents` | 6 项目录 |
| `DIR-10` | `contents` | 10 项紧凑目录 |
| `SEC-01` | `transition` | 章节编号、标题和可选说明 |
| `CNT-02` | `content` | 2 项纯文字内容 |
| `CNT-03` | `content` | 3 项纯文字内容 |
| `CNT-04` | `content` | 4 项纯文字内容 |
| `END-01` | `end` | 结束标题和可选说明 |

MVP 必须先通过真实生成、长文本、图片保护和 PPTX 往返测试。未通过前，不扩展生产版。

### 4.2 18 页生产版

MVP 通过后增加以下 6 页：

| 页面代码 | 类型 | 用途 |
|---|---|---|
| `COV-02` | `cover` | 第二封面，改变标题和装饰方向 |
| `SEC-02` | `transition` | 带一个独立内容图片槽的章节页 |
| `CNT-01` | `content` | 单结论、核心观点或长引言 |
| `CNT-IMG-01` | `content` | 单图文，1 个独立内容图片槽 |
| `CNT-MET-03` | `content` | 三项数据指标，`layoutKind: "metrics"` |
| `CNT-04B` | `content` | 四步流程、SWOT 或四项内容第二构图 |

生产版共 18 页：2 个封面、6 个目录、2 个章节、7 个内容页和 1 个结束页。

### 4.3 选版规则

- 目录按 `items` 数量选择精确匹配的页面。
- 普通内容按 1、2、3、4 项选择对应容量页面。
- `CNT-04` 与 `CNT-04B` 继续使用现有 `title/items` 语义。
- 数字、百分比、金额、年份等指标内容可以触发 `metrics` 页面。
- 有 Agent 配图时优先选择图文页；无图时不保留空图片框。
- 超过四项或超出可读容量的正文由渲染器分页，不允许静默截断。

## 5. 视觉系统与核心素材

### 5.1 颜色与字体

| 用途 | 色值 |
|---|---|
| 深海蓝 | `#123B58` |
| 主蓝 | `#28688A` |
| 雾蓝 | `#86B5C4` |
| 灰绿色 | `#A9B9A8` |
| 象牙白 | `#F5F2DF` |
| 浅金灰 | `#C8C2A4` |
| 主文字 | `#193342` |
| 次文字 | `#62747C` |
| 浅色背景 | `#F8F8F3` |
| 反白文字 | `#FFFFFF` |

- 中文使用微软雅黑。
- 英文和数字使用 Arial。
- Wingdings 图标改为 PPTist 原生形状或授权明确的 SVG/PNG。
- 封面标题不低于 50px，页面标题不低于 35px。
- 内容项标题不低于 24px，正文和目录不低于 16px。
- 自动适配下限为 12px；仍放不下时必须拆页。

### 5.2 页面安全区

- 画布固定为 1000 × 562.5。
- 左右安全边距建议为 56～64，底部不少于 28。
- 封面至少保留 55% 连续标题区域。
- 章节页至少保留 55% 连续标题和说明区域。
- 普通内容页中央约 75% 保持低干扰。
- 流体装饰集中在边缘，不穿过标题、正文、数据和内容图片。
- 单行页面标题不能因替换文案意外换成两行。
- 图片框必须验证横图、竖图和方图的居中裁切。

### 5.3 V1 核心素材

首版只生产 7 项必要素材。第二封面通过不同裁切、原生形状和装饰方向形成差异，不单独生产第二张封面背景。

| 文件名 | 格式和尺寸 | 目标体积 | 用途和构图要求 |
|---|---|---:|---|
| `template_11_asset_bg_cover_v1.jpg` | JPG RGB，1920×1080 | 小于 350KB | 主封面；流体集中在右侧和边缘，左侧保留标题区 |
| `template_11_asset_bg_section_v1.jpg` | JPG RGB，1920×1080 | 小于 300KB | 章节页；焦点偏右，左侧保留标题和说明 |
| `template_11_asset_bg_end_v1.jpg` | JPG RGB，1920×1080 | 小于 300KB | 结束页；与封面同系列，中央低干扰 |
| `template_11_asset_fluid_corner_blue_v1.png` | PNG RGBA，1200×1200 | 小于 1MB | 深蓝流体角落装饰，必须真透明 |
| `template_11_asset_fluid_corner_ivory_v1.png` | PNG RGBA，1200×1200 | 小于 1MB | 浅色内容页角落装饰，不遮挡正文 |
| `template_11_asset_fluid_ribbon_v1.png` | PNG RGBA，1800×500 | 小于 1MB | 封面或章节使用的横向流体带 |
| `template_11_asset_marble_orb_v1.png` | PNG RGBA，1200×1200 | 小于 1MB | 指标页和目录页的液态纹理球体 |

模板列表封面另存为 `template_11.jpg`，尺寸 960×540、RGB JPEG，建议小于 350KB。

### 5.4 素材验收规则

- 素材必须原创或具有明确商用授权。
- 不包含文字、字母、数字、Logo、水印和签名。
- 不包含按钮、假界面、假图表、假截图和可识别真人。
- PNG 必须具有真实 Alpha 通道，不能带白底、棋盘格或矩形边缘。
- 流体纹理集中在指定边缘，保留文字安全区。
- 每项素材单独生成，不制作难以裁切复用的素材拼图。
- 保存最终提示词、工具与模型、原始输出、发布路径、授权和人工检查结果。

以下元素使用 PPTist 原生形状，不制作位图：

- 卡片、边框、分隔线、底板和普通阴影。
- 百分比圆环、数据条、指标数字和 SWOT 字母。
- 流程编号、步骤节点、箭头、连接线和章节编号。
- 标题、正文、图片裁切框和半透明遮罩。

## 6. PPTist 标注与模板数据

### 6.1 页面和文字角色

每个页面必须标注为 `cover`、`contents`、`transition`、`content`、`end` 中的一种。

| `textType` | 用途 |
|---|---|
| `title` | 页面主标题 |
| `content` | 封面副标题、章节说明或长正文 |
| `item` | 目录项或内容项正文 |
| `itemTitle` | 内容项标题 |
| `itemNumber` | 目录项或内容项编号 |
| `partNumber` | 章节编号 |
| `subtitle` | 图片说明或次级标题 |

同一个内容项的编号、标题、正文和伴随形状使用相同 `groupId`。内容不足时删除整个未使用分组，不能留下空编号、空卡片或孤立装饰。

### 6.2 图片角色

- 固定背景和装饰使用 `imageType: "decoration"` 或项目已支持的背景类型，并锁定。
- 可以被 Agent 或用户替换的业务图片使用 `imageType: "content"`。
- 与内容项绑定的图片可以使用 `itemFigure`。
- 内容图片必须保持可选中和可替换，不能与装饰合并成一张图。
- 单图文页使用严格图片数量约束，确保图片和内容项一一对应。
- 需要裁切的内容图片必须提供源图宽高。
- 没有图片输入时选择纯文字页，不留下空图片框或破图。

### 6.3 `template_11.json` 硬约束

- 路径为 `backend/main_api/template/template_11.json`。
- 顶层 `id` 为 `template_11`，`title` 为“蓝金流体创意”。
- `width` 为 1000，`height` 为 562.5。
- 顶层包含 `slides`、`theme` 和 `metadata`。
- `metadata.mvpSlideIds` 精确包含第 4.1 节的 12 个 MVP 页面。
- 生产版包含第 4 章定义的 18 个页面。
- 页面 ID 和元素 ID 全部唯一。
- 图片使用 `/api/data/` 地址，不内嵌 Base64 大图。
- 所有外置资源真实存在，并至少被一个页面引用。
- JSON 建议小于 1MB。
- 所有图片具有明确的内容或装饰角色。
- 不包含示例文案、失效 URL、本机路径、临时目录和版权来源文字。

## 9. 风险、阶段门与待确认事项

### 9.1 主要风险

| 风险 | 控制措施 |
|---|---|
| 原稿授权不明确 | 只参考构图，使用原创或授权素材重建 |
| 流体背景干扰文字 | 固定安全区，视觉焦点集中在边缘 |
| 没有语义占位符 | 在 PPTist 中重新标注页面、文字、分组和图片 |
| 非标准字体替换 | 统一微软雅黑和 Arial，导出后检查换行 |
| 相似版式过多 | 只保留容量和用途明确的 18 页 |
| 装饰被 Agent 换图 | 隔离 `content` 与 `decoration` 并增加测试 |
| 长内容挤压页面 | 按容量选版，超量和超长内容无损分页 |
| 透明素材出现白边 | 检查 Alpha、边缘和不同底色下的渲染 |
| 单模板修改渲染器 | 必须先由测试证明缺口，并执行旧模板回归 |

### 9.2 三个自动质量检查点

1. **素材检查点**：授权无法确认时不复用原稿素材，自动使用 GPT2 图片模型或授权明确的原创替代，不暂停其他工作。
2. **MVP 检查点**：12 页未通过生成、分页、图片保护和导出时自动修复并重试；通过后自动扩展到 18 页。
3. **最终检查点**：专项测试、旧模板回归、编辑、换图、导出和多设备全部通过后，自动进入 `READY_FOR_CONFIRMATION`，等待人工确认闭合。

G0～G7 的检查点是自动质量控制，不是人工审批门禁。涉及无关文件、额外范围或发布操作时，默认跳过并记录，不暂停模板主体开发。只有 G8 自动验收后的最终闭合需要人工确认。

### 9.3 自动默认决策

- 未取得参考 PPT 商用授权证明时，不复用原稿媒体，自动使用原创替代。
- 默认采用“蓝金流体创意”和 `template_11`；如果 ID 已占用，自动选择下一个可用 `template_N`，并同步更新文件、测试和文档。
- 自动删除生产副本中的音乐、动画、切换、山水照片和其他未授权素材。
- 三张视觉样稿按本开发说明自动检查，通过后直接进入 12 页 MVP，不增加人工确认环节。

### 9.4 完成定义

模板满足以下条件后自动进入 `READY_FOR_CONFIRMATION`：

- 12 页 MVP、18 页生产版和全部生产资源完成。
- 专项测试、通用测试、旧模板回归和多设备 QA 通过。
- 真实生成、文字编辑、换图、PPTX 导出和重新导入通过。
- 素材、授权、提示词、截图、测试和已知限制记录完整。

全部必需条件通过后提交最终报告并等待人工确认。只有用户明确确认完成后，模板状态才更新为 `DONE`；必需条件未通过时继续修复，不得提前请求闭合。
