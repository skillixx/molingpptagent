## 2. 模板定位与参考稿结论

### 2.1 产品定位

“飞檐雅韵”是一套东方古建风格的通用生产模板，主要面向文化宣传、城市文旅、品牌介绍、企业汇报和项目方案。

核心视觉为粉黛灰瓦、飞檐马头墙、梅枝飞鸟、藕粉竖带和宣纸米白留白。朱砂与哑金只做小面积点缀。

动态标题、正文、目录、编号、指标和业务图片必须保持清晰、可编辑、可生成。装饰不得压过信息层级。

### 2.2 与 `template_12` 的差异

| 维度 | `template_12 东方水墨雅韵` | `template_18 飞檐雅韵` |
|---|---|---|
| 主视觉 | 山水、折扇、墨圈 | 灰瓦、飞檐、马头墙、梅枝 |
| 主色 | 米白、墨蓝、山水青 | 米白、藕粉、瓦灰、深墨 |
| 章节识别 | 印章、墨圈、山影 | 藕粉竖带、圆纹章、飞檐角景 |
| 页面气质 | 写意山水 | 古建雅集与庭院意象 |

本模板不复用 `template_12` 的折扇、墨圈和印章素材。圆形构图使用抽象古典纹章或可编辑圆形。

### 2.3 参考稿关键结论

| 项目 | 结论 | 开发影响 |
|---|---|---|
| 页面 | 26 页、16:9 | 可覆盖封面、目录、章节、内容和结束页 |
| 页面结构 | 全部使用空白版式，没有结构化占位符 | 必须按项目 JSON 和语义槽重建 |
| 导入 | 底层可解析，编辑器遇到 `fill=null` 会失败 | 不直接把 UI 导入结果作为生产模板 |
| 字体 | 主要字体含“非商业使用”，且未嵌入 | 全部替换为授权明确的稳定字体 |
| 权利 | 母版含包图网版权提示 | 不复制原媒体，素材必须原创或授权明确 |
| 圆形图片 | 导出重导入后会变成矩形 | 使用项目 `clip` 契约重建并测试 |
| 原生图表 | 第 22 页图表在重导入后丢失 | 四指标页使用可编辑文字和形状 |
| 音频和动画 | 无法稳定回环 | V1 排除音频、动画和页面切换 |

参考稿可以作为视觉和页面关系来源，但不能原样发布，也不能复制媒体字节到生产目录。

### 2.4 权利和清理规则

- 原图片、插画、纹样、音频和包图网内容不进入生产模板。
- 非商业字体和授权不明字体统一替换。
- 原生图表改为可编辑数字、圆环和基础形状。
- 示例标题、正文、年份和固定数据改为中性预览文案和语义槽。
- 不使用真实机构印章、Logo、二维码、个人信息和伪造业务数据。
- 不实现复杂表格、SmartArt、视频和三维模型。

MVP 通过后增加以下 6 页：

| 页面 ID | 类型 | 用途 |
|---|---|---|
| `cover-eaves` | `cover` | 带一张业务图片的第二封面 |

| `content-image-1` | `content` | 一张内容图加一项正文 |

| `end-action` | `end` | 1～3 项行动结束页 |

生产版库存为 2 张封面、6 张目录、2 张章节、6 张内容和 2 张结束页，共 18 页。

### 4.3 选版和分页

- 目录按 2、3、4、5、6、10 项选择精确容量页面。
- 无图内容按 1、2、3、4 项选择对应内容页。
- 一项内容加一张业务图片选择 `content-image-1`。
- 数字语义选择 `content-metrics-4`，不使用原生图表。
- 超过 4 项的普通内容和超过 10 项的目录必须无损分页。
- 超长正文分页后不得丢字、改序、重复或低于最小字号。
- 带图长正文只在第一页保留内容图，续页不保留空图片框。
- 无图输入不得显示空业务图片占位。
- 两个封面和两个章节页必须通过稳定条件分别可达。
- 结束页按 0 项和 1～3 项行动选择版式，超过 3 项应显式失败。

## 5. 视觉系统

### 5.1 画布与安全区

| 项目 | 规范 |
|---|---|
| 逻辑画布 | `1000 × 562.5`，16:9 |
| 左右安全边距 | 55～64px |
| 上下安全边距 | 40～46px |
| 页面标题区 | 70～92px |
| 正文与装饰最小距离 | 20px |
| 底部瓦片最大侵入高度 | 页面高度的 22% |
| 角部飞檐最大侵入宽度 | 页面宽度的 30% |
| 竖排文字 | 仅限 2～8 个字的章节或装饰标题 |

正文、目录和指标说明全部横排。单行标题不得因替换文案意外换成两行。

### 5.2 色彩

| 角色 | 色值 | 用途 |
|---|---|---|
| 宣纸米白 | `#F6F2EA` | 主背景 |
| 藕粉主色 | `#B77D80` | 章节竖带和弱强调 |
| 深墨黑 | `#211B1C` | 封面圆形和核心标题 |
| 瓦片灰 | `#4D4D4B` | 古建装饰和辅助文字 |
| 暖灰正文 | `#4A4643` | 正文 |
| 朱砂红 | `#A83F36` | 小编号和视觉焦点 |
| 哑金 | `#B6925F` | 圆纹章和少量细线 |
| 淡粉背景 | `#E9DADB` | 图片底板和弱分区 |

朱砂和哑金只用于小面积焦点。普通内容页以米白和暖灰为主，避免每页都出现重瓦片和大面积藕粉。

### 5.3 字体与字号

| 层级 | 字体 | 目标字号 | 最低字号 |
|---|---|---:|---:|
| 封面标题 | 授权宋体或项目稳定中文标题字体 | 50～64px | 50px |
| 章节标题 | 授权宋体或微软雅黑 Bold | 44～52px | 44px |
| 页面标题 | 微软雅黑 Bold | 35～40px | 35px |
| 内容项标题 | 微软雅黑 Bold | 24～28px | 24px |
| 正文、目录项 | 微软雅黑 | 16～20px | 16px |
| 英文和数字 | Arial | 跟随对应层级 | 12px |
| 辅助说明 | 微软雅黑 | 14～16px | 12px |

内容无法容纳时必须换版或分页。自动缩字不得低于元素声明的 `minimumFontSize`。

### 5.4 位图与可编辑元素

| 使用位图 | 使用 PPTist 可编辑元素 |
|---|---|
| 灰瓦、飞檐、马头墙和梅枝 | 标题、正文、目录、章节编号和页码 |
| 写意双鹤和飞鸟 | 封面四个深墨圆形和藕粉竖带 |
| 抽象古典圆纹章 | 分隔线、指标圆环和简单数据图形 |
| 大面积古建背景和远景 | 内容图片框、裁切、边框和常规阴影 |

固定装饰使用 `imageType: "decoration"`。业务图片槽使用 `imageType: "content"`，两者不得混用。

### 6.1 素材生产要求

- 模板所需的原创背景和透明装饰可以优先使用 GPT Image 2（`gpt-image-2`，本文简称“GPT2 图片模型”）生成。
- 实际执行必须通过当时可用的图片生成技能或工具；工具不可用或未暴露实际模型名称时，应如实记录，不能猜测或伪造模型信息。
- 背景使用 JPEG，透明装饰使用具有真实 Alpha 通道的 PNG。
- 每张素材单独生产，不生成需要二次切割的素材拼图。
- 素材不得包含文字、数字、Logo、水印、二维码和真实机构印章。
- 不生成可识别真人、真实产品界面、证书和业务数据。
- 背景按预定文字区留出安全空间，装饰不得紧贴图像边缘。
- 透明素材不得带白底、灰底和半透明白边。
- 每张素材保存原始输出、发布文件、提示词、工具、模型、授权和人工检查记录。
- 发布前检查格式、尺寸、色彩模式、Alpha、体积和实际引用。
- 禁止复制、改名或轻微处理参考 PPTX 的媒体后作为新素材。

## 7. PPTist 语义与资源契约

### 7.1 页面与文字角色

生产页面只使用 `cover`、`contents`、`transition`、`content` 和 `end`。

| 文字角色 | 用途 |
|---|---|
| `title` | 封面、页面或章节标题 |
| `content` | 副标题、章节说明、单结论和结束说明 |
| `item` | 目录项、正文和行动项 |
| `itemTitle` | 内容项标题 |
| `itemNumber` | 目录或内容编号 |
| `partNumber` | 章节编号 |

普通文本使用 `textType`。带文字形状使用 `element.text.type`。页面 ID 和元素 ID 在整份模板中必须唯一。

所有动态文字槽必须声明可读的 `minimumFontSize`。示例文字不得进入生产语义。

### 7.2 图片角色

| 图片角色 | 行为 |
|---|---|
| `imageType: "content"` | Agent 可填图，用户可替换，必须声明裁切和分组关系 |
| `imageType: "decoration"` | 固定模板装饰，不得被业务图片替换 |

内容图片必须提供逻辑尺寸和原始尺寸，使用稳定居中裁切，并覆盖横图、竖图和方图。

内容图片应与对应标题和正文共享 `groupId`。导出重导入后，图片仍需可选中和替换。

### 7.3 资源和对象限制

- 装饰资源使用 `/api/data/template_18_asset_*`。
- 禁止 Base64 大图、`file://`、本机绝对路径和临时目录。
- 所有发布素材必须存在并至少被一个生产页面引用。
- `template_18.json` 建议小于 1MB。
- `template_18.jpg` 固定为 960×540、RGB JPEG，建议小于 150KB。
- 生产页面不包含 `animations`、音频、视频和自动播放行为。
- 生产 JSON 不包含原生 `chart` 对象。
- 四指标页使用可编辑数字、圆环、分隔线和文字。

### 7.4 导入兼容说明

参考稿直接导入存在 `fill=null` 兼容问题。该问题属于通用前端能力，不作为模板 MVP 的前置条件。

如需修复，应创建独立任务，覆盖空填充安全访问、导入状态恢复、错误反馈和原有 PPTX 回归。模板主线仍按原创素材和 JSON 语义重建。

## 9. 风险与验收门槛

### 9.1 主要风险

| 风险 | 影响 | 处理方式 |
|---|---|---|
| 源媒体和字体授权不明 | 无法合法发布，字体发生替换 | 不复用原媒体，使用原创素材和稳定授权字体 |
| `fill=null` 导入异常 | 源稿无法直接通过 UI 导入 | 作为独立兼容任务，不阻塞模板 MVP |
| 圆形裁切回环退化 | 圆图重导入后变成矩形 | 使用项目 `clip` 契约并覆盖三种宽高比 |
| 原生图表丢失 | 四指标页重导入后内容消失 | 使用可编辑文字和形状 |
| 与 `template_12` 重复 | 模板选择缺少差异价值 | 固定灰瓦、飞檐、藕粉竖带和古建纹章识别 |

### 9.2 自动测试门槛

- 18 页生产库存和 12 页 MVP ID 准确，构建结果确定。
- 2、3、4、5、6、10 项目录和 1～4 项正文精确选版。
- 超量目录、超量内容和长正文分页不丢字、不改序。
- 横图、竖图和方图裁切正确，内容图与装饰图严格隔离。
- 封面、章节、四指标和 0～3 项行动结束页均可达。
- 资源尺寸、格式、Alpha、体积、路径、引用和授权满足契约。
- 模板不包含包图网文字、原媒体、非商业字体、音频、动画和原生图表。
- 专项测试、公共渲染器回归、前端相关单测和类型检查通过。

### 9.3 端到端门槛

- 使用真实持久任务生成封面、目录、章节、内容和结束页。
- 标题和正文可编辑，业务图片可替换，固定装饰不被误替换。
- 1920×1080、1366×768、768×1024、390×844 四种视口没有操作遮挡。
- 返回、保存、换图、导出和失败重试都有加载、成功、失败或重试反馈。
- PPTX 导出和项目同款重导入后，页数、文字、图片和装饰保持稳定。
- 圆形图片仍为圆形，四指标页不丢失，内容图片仍可选中和替换。

所有中间条件都是自动检查点，不逐项请求人工确认。自动检测没有问题后，状态只更新为 `READY_FOR_CONFIRMATION` 并停止闭合操作；用户明确人工确认后，才能更新为 `DONE` 或 `DONE_WITH_CONCERNS`。
