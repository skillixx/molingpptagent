# TrainPPTAgent 墨灵对接 Goal 顺序开发提示词

> 用途：一次创建总 Goal，按照 T01 → T23 自动顺序开发。
> 执行依据：[Goal 开发执行主文档](./TrainPPTAgent墨灵对接Goal开发执行主文档.md)
> 需求依据：[全阶段开发规划](./TrainPPTAgent对接墨灵平台全阶段开发规划.md)
> 项目目录：`D:\molinggithub\TrainPPTAgent`

## 1. 使用前说明

如果当前已经存在未完成的单任务 Goal，请先在 Goal 界面取消或结束它，再粘贴下面的“总 Goal 提示词”。系统同一时间只能存在一个活动 Goal。

总 Goal 会自动完成本地代码、测试、文档和Mock联调。遇到以下情况才暂停等待用户：

1. 需要真实扣除积分、修改生产数据或切换生产流量。
2. 需要创建、删除或覆盖云资源。
3. 需要提交、推送、合并或发布代码，但用户尚未授权。
4. 需求文档没有默认值，而且不同选择会明显改变用户成本或数据结果。
5. 同一外部阻塞连续出现三次，无法继续推进依赖任务。

## 2. 一次性总 Goal 提示词

直接复制下面整段：

```text
创建 Goal：完成 TrainPPTAgent 对接墨灵平台的全部开发工作。

项目目录：D:\molinggithub\TrainPPTAgent

执行依据：
1. molin_docs/TrainPPTAgent墨灵对接Goal开发执行主文档.md
2. molin_docs/TrainPPTAgent对接墨灵平台全阶段开发规划.md
3. molin_docs/app/developer-integration-guide.md
4. molin_docs/app/billing-integration-spec.md
5. 当前仓库代码、测试与配置契约

总目标：
按照执行主文档的依赖关系，连续完成 T01 到 T23。不要要求我逐个发送任务提示词。
完成一个任务后，立即验证、更新执行主文档的项目状态块、任务状态、阻塞项和证据记录，
然后自动开始下一个依赖已满足的任务。只有整个项目完成或触发明确暂停条件时才结束 Goal。

固定执行顺序：
M0：T01 → T02
M1：T03 → T04 → T05
M2：T06 → T07 → T08
M3：T09 → T10 → T11
M4：T12 → T13 → T14
M5：T15 → T16 → T17 → T18
M6：T19 → T20
M7：T21
M8：T22 → T23

允许在依赖已经满足时并行分析，但代码落地、验证和状态更新必须保持任务边界清晰。
不得为了加快速度跳过 G0～G5，也不得把后续任务代码混进当前任务。

每个任务必须执行以下循环：
1. 读取执行主文档中的项目状态块、阻塞项、运营决策、任务卡和当前 Gate。
2. 运行 git status --short，识别并保留用户已有修改；禁止 reset、clean、checkout 覆盖或删除无关文件。
3. 核对当前实现、测试、配置和接口文档；不能只根据规划猜测代码。
4. 将当前任务标记为 in_progress，并用 update_plan 展示当前任务步骤。
5. 优先测试驱动：先确定公开行为测试边界，再写失败测试，确认红灯后实现最小完整功能。
6. 新增或修改代码使用中文注释解释业务规则、安全边界、并发和幂等语义。
7. 前端页面必须适配 1440、1024、768、390 四档设备宽度。
8. 运行当前任务单测、相关集成测试、类型检查和必要的真实验证。
9. 检查错误路径、越权、重试、幂等、日志脱敏、回滚和旧功能回归。
10. 只审查当前任务差异，修复审查发现的阻塞问题。
11. 在执行主文档写入修改文件、测试命令、通过数量、真实验证、未验证边界和回滚方法。
12. 只有验收项和证据全部满足时才将任务标记 completed，并把 current_task 推进到下一任务。

自动决策规则：
- 可逆、本地、低风险的技术细节，按照执行主文档的默认决策实施，不重复向我提问。
- 计费金额、多权益选择、容量和保留规则优先采用执行主文档中的推荐默认值，并保持为配置项。
- 在真实运营值未确认前，可以完成代码、Mock测试和契约测试，但 BILLING_ENABLED 必须保持 false。
- 真实墨灵、真实对象存储和现有环境变量可以用于只读或最小联调，但不得在输出、日志、测试或文档中打印密钥。
- 不得把 Mock 200、本地端口监听或静态代码判断写成真实平台验收通过。
- 知识库转换、Embedding、依据文件生成、PPTX打开和视觉结果必须分别验证并分别报告。

失败处理规则：
- 普通代码或测试失败：调查根因并安全修复，最多连续尝试三种有证据的方案。
- 某任务被外部条件阻塞：记录 blocker、已尝试内容和解除条件；继续执行不依赖它的任务。
- 依赖链被阻断时：停止跨越该 Gate，不伪造完成状态，向我汇报一个最小决策请求。
- 服务或端口异常：先确认进程属于本项目，禁止停止未知项目进程。

权限边界：
- 允许：修改当前 TrainPPTAgent 仓库中的代码、测试、配置模板和开发文档；运行本地测试、构建和只读诊断。
- 禁止：修改 D:\molingproject\molinppt 或墨灵平台源代码；删除现有用户数据；创建或删除生产云资源；开启真实生产计费；切换生产流量。
- 未经我单独明确授权，不执行 git commit、git push、创建PR、合并或部署。

阶段 Gate：
- G0通过后才进入SSO开发。
- G1通过后才开放历史作品和计费身份。
- G2通过后才开放生产作品库。
- G3通过后才允许准备真实计费验收。
- G4通过后才开放历史归档下载。
- G5通过后整个Goal才能完成。

完成标准：
- T01～T23全部完成并有证据。
- B-01～B-08全部关闭或通过明确缩减范围关闭。
- G0～G5全部通过。
- 用户能从墨灵进入、生成、找到、打开、编辑、保存、导出并再次下载PPT。
- 多用户隔离、任务恢复、计费幂等、对象存储、四档UI和PowerPoint实际打开完成验收。
- 生产页面不依赖Vite开发服务。
- 执行主文档、配置模板、迁移、部署与实际代码一致。

当前从 T01 开始。开始后持续推进，不要等待我逐项回复。
```

## 3. 推荐的分阶段 Goal 提示词

如果一次执行全部T01～T23时间过长，可以按阶段创建9个Goal。每个阶段内部不需要逐任务发送提示词。

### M0：T01～T02

```text
创建 Goal：按照 Goal 开发执行主文档连续完成 M0 的 T01～T02，并通过 G0。
自动完成配置模板、集中配置校验、功能开关、ORM、迁移和MySQL基线。
关闭或明确记录 B-01～B-08 的解决路径。每完成一个任务自动更新执行主文档并继续。
只修改 TrainPPTAgent，不提交、不推送、不执行生产迁移。
```

### M1：T03～T05

```text
创建 Goal：按照 Goal 开发执行主文档连续完成 M1 的 T03～T05，并通过 G1。

每完成一个任务自动更新文档并继续，不提交、不推送、不切生产流量。
```

### M2：T06～T08

### M3：T09～T11

### M5：T15～T18

完成权益解析、计费型任务幂等、reserve/settle/release和billing_pending自动对账。

## 4. 继续执行提示词

Goal被中断或会话压缩后，复制：

```text
继续当前 Goal。
读取 molin_docs/TrainPPTAgent墨灵对接Goal开发执行主文档.md 的项目状态块、
任务总看板、当前任务卡和最新执行记录；运行 git status --short，保留已有修改。
从 current_task 的第一个未完成验收项继续。完成后自动推进后续任务，不要求我逐项回复。
不得把上次未验证的内容标记完成。
```

## 5. 状态检查提示词

```text
只检查当前总 Goal 状态，不修改代码和外部系统。
读取 Goal 执行主文档并报告：当前阶段、当前任务、已完成任务、阻塞项、
最近测试证据、未验证边界、下一步以及是否可以继续自动推进。
```

## 6. 阻塞恢复提示词

```text
恢复当前被阻塞的 Goal。
先读取执行主文档中的 blocker、已尝试内容和解除条件，再检查当前环境是否已经变化。
不要重复执行没有新证据的失败方案。若阻塞已解除，继续当前任务并自动推进；
若仍被阻塞，执行所有不依赖该阻塞的任务，禁止跨越对应Gate或伪造完成。
```

## 7. 最终验收提示词

```text
对 TrainPPTAgent 墨灵对接总 Goal 做最终验收，不新增范围。
逐项核对 T01～T23、B-01～B-08、O-01～O-09 和 G0～G5，
运行全量自动化、前端构建、两用户隔离、任务恢复、计费幂等、对象存储、
四档响应式、真实墨灵入口和PowerPoint打开验证。
明确区分自动化、Mock、真实平台、真实存储和人工验证。
发现缺口时恢复对应任务，不得仅修改文档把项目标记完成。
未经明确授权不提交、不推送、不部署或产生真实扣费。
```

## 8. 推荐使用方式

优先使用第2节“一次性总 Goal 提示词”。只有在总Goal因时间或上下文过长需要拆分时，才使用第3节的阶段提示词。不要再为T01～T23分别创建23个Goal。
