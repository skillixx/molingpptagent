| 项目 | 内容 |

## 目标

在不降低规格、版权、安全、测试和 QA 门禁的前提下，完成以下结果：

- 生产模板 JSON、封面和所有外置素材；
- 页面、文字、内容图片和装饰图片语义正确；
- 容量、分页、裁切和错误边界符合规格；
- 模板注册、专项测试和受影响回归通过；
- 真实任务、编辑、换图、四视口和 PPTX 往返有可复查证据；
- 自动状态进入 `READY_FOR_CONFIRMATION`，等待人工确认。

## 不包含的动作

- 不自动 Commit、Push、创建 PR 或合并 `main`；
- 不自动重启或部署项目；
- 不自动执行数据库迁移、计费或回滚；
- 不自动把 Goal 标记为 `DONE`。

## 前置门禁

- [ ] 规格状态为 `READY_FOR_BUILD`。
- [ ] 当前请求明确授权图片生成、代码修改和真实 QA。
- [ ] 规格 SHA-256 与规划记录一致。
- [ ] 参考文件存在且 SHA-256 一致。
- [ ] 候选模板 ID 重新扫描后仍无冲突。
- [ ] 当前协议、注册入口和测试入口已重新发现。
- [ ] 工作区已有修改已记录且不会被覆盖。

## 阶段任务

### 1. 开发预检

- 校验规格、哈希、候选 ID、仓库漂移和权限。
- 记录项目解释器、测试入口和证据目录。

完成条件：{{preflight_completion}}

### 2. 素材生产与审计

- 按 manifest 逐项生成，记录提示词、工具和可见模型信息。
- 验证格式、尺寸、Alpha、体积、安全区、权利和重试上限。

完成条件：{{asset_completion}}

### 3. MVP 构建与真实门禁

- 构建 MVP 页面、语义槽和资源引用。
- 通过真实生成验证后才进入生产版扩展。

完成条件：{{mvp_completion}}

### 4. 生产版扩展与注册

- 完成页面矩阵、专项版式、封面、外置素材和唯一注册。

完成条件：{{production_completion}}

### 5. 自动化测试

- 运行模板专项、通用渲染器、素材和受影响回归。
- 前端源码发生变化时运行前端类型检查、单测与构建。

完成条件：{{test_completion}}

### 6. 真实端到端 QA

- 完成真实 Worker 任务、编辑保存、换图、装饰保护、失败重试和四视口。
- 导出、解析、重导入 PPTX 并验证继续编辑。

完成条件：{{qa_completion}}

### 7. 证据与自动闭合

- 汇总 `evidence.json`、关键截图、蒙太奇、素材摘要和已知限制。
- 门禁通过后更新实施状态为 `READY_FOR_CONFIRMATION`，不得生成 `DONE`。

完成条件：{{evidence_completion}}

## 阻断与人工确认

模板 ID 冲突、参考哈希漂移、页面或视觉范围变化、素材角色减少、QA 门禁降低、外部服务不可用或重试上限耗尽时，记录 `BLOCKED` 并停止扩大操作。

人工确认语句应明确表达模板验收是否通过。只有收到明确确认后，主 Agent 才能更新 Goal 闭合状态；发布仍需单独授权。
